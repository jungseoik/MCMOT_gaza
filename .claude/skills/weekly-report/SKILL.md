# 주간(weekly) 작업 보고서 — 작성 컨벤션

사용자 요청으로 weekly 폴더에 넣을 보고서를 쓸 때 이 양식·말투를 따른다.
**예외: WBS 진척 보고서(`WBS-진척점검.md`)는 `wbs-review` 스킬이 담당** — 표 중심의
별도 양식이라 여기 규칙을 적용하지 않는다.

기준 예시: [2026-06-3주차 C-LAB 시각화 보고서](../../../docs/weekly/2026-06-3주차/2026-06-16_삼성화재-주간미팅-clab샘플-시각화-보고서.md)

## 말투 / 제목 규칙 (가장 중요)

1. **섹션 제목은 명사형으로.** 의문문·설명구를 제목에 붙이지 않는다.
   - ❌ `## 1. 목적 — 왜 이 영상들을 시각화했나`
   - ❌ `## 4. 핵심 요구사항 대비 — 무엇을 확인하려 했나`
   - ✅ `## 1. 목적` / `## 4. 핵심 요구사항 대비`
2. **제목에 담고 싶던 의문/맥락은 본문 첫 도입문장으로 옮긴다.**
   - 예) `이 영상들을 시각화한 목적은 다음과 같다.` 로 섹션을 연다.
   - 예) `확인하려는 기준은 [북극성 5대 …]다. … 구분하면 다음과 같다.`
3. **말투는 명사형 종결(개조식)을 기본**으로 한다 — 단정적 서술 문장은 명사로 끝맺는다.
   - 예) "매칭된다" → "매칭", "확인한다" → "확인", "표시된다" → "표시", "처리한다" → "처리",
     "나타난다" → "표시"(명사 재구성).
   - 도입·접속 문장은 자연스러우면 `~다.` 허용(예: "~목적은 다음과 같다.", "~기준은 …다.").
   - 지양: 장황한 동사 종결(`~된다/한다/이다`)과 메모체(`~함/됨/음`).
   - 불릿도 명사구로 끝맺는다(예: "…이 심한 환경", "…느리게·간헐적으로 이동").
4. 과장 금지 — 사실 기준으로 쓰고, 미완성/데모 단계는 그렇게 명시.

## 문서 구조

**헤더(파일 맨 위)**
- `# <제목>` (명사형, 예: "삼성화재 주간 미팅 — C-LAB 샘플 영상 추적 시각화 보고서")
- 메타 블록(불릿): `**작성일**` · `**대상**` · `**데이터셋/대상물**` · `**결과물**` · 필요 시 `**엔진/도구**`
- 관련 문서 인용(blockquote): 북극성 요구사항 등 관련 링크
- 구분선 `---`

**본문 섹션(권장 골격, 내용에 맞게 가감)** — 각 섹션은 도입문장으로 시작
1. **목적** — 왜 했는지를 도입문장 + 배경/특성(불릿)
2. **데이터셋 / 현황** — 요약 표(개수·총량 등) + 분포/상세 표
3. **방법** — 파이프라인(코드블록 다이어그램 가능) + 핵심 선택/제약
4. **결과** — 이미지 첨부(아래 규칙). 대표 장면은 굵은 라벨 + 1~2문장 설명
5. **핵심 요구사항 대비** — [북극성 5대 정보](../../../docs/requirements/CCTV-영상분석-엔진-필수추출정보.md) 기준 충족/미흡 표
6. **관찰 및 한계** — 강점 / 현재 한계 / 다음 단계(번호 목록)
7. (선택) **부록** — 재현 명령 등

## 파일 위치 / 이미지

- 위치: `docs/weekly/YYYY-MM-N주차/` (그 주 폴더. 없으면 만들고 `README.md`도).
- 파일명: `YYYY-MM-DD_제목.md` (한국어).
- 이미지: 같은 폴더의 `img/`에 두고 상대경로 `![설명](img/파일.png)`로 첨부.
  - 영상 대표 프레임: `ffmpeg -y -loglevel error -ss <s> -i <영상> -vframes 1 img/<이름>.png`
  - 여러 결과 요약: 몽타주 1장(track-viz의 `tools/montage.sh`) 활용.
- 작성 후 그 주차 `README.md` 표에 문서 1줄 추가.
- 상위 링크는 폴더 깊이에 맞춰 상대경로 보정(주차 폴더 기준 `../../requirements/...`).

## 체크리스트 (작성 후)
- [ ] 모든 `##`/`###` 제목이 명사형인가(의문구·`— 무엇/왜…` 없음).
- [ ] 본문 단정 서술이 명사형 종결(개조식)인가 — 동사 종결(된다/한다)·메모체(함/됨/음)가
  남지 않았는가(도입·접속문만 `~다.` 허용).
- [ ] 각 섹션이 도입문장으로 시작하는가.
- [ ] 이미지가 `img/` 상대경로로 실제 표시되는가.
- [ ] 주차 `README.md` 인덱스에 추가했는가.
