### 영상 한 편의 흐름

1. **인트로 4초** — 도면·피난경로 소개(시계 0:00 이전).
2. **본편** — 하단 시계 0:00 = 경보(훈련 시작, 실제 14:59:55). 지표는 시간에 따라 쌓인다.
3. **종료 정지 3초** — 컷 시각의 마지막 화면을 멈추고 라벨(예: "16층 피난층 종료 · 08:10")을 띄운다.
4. **리포트**(있을 때만) — 우리 UI 의 결과 리포트 화면 클립(`tools/report_card.py`).

### 용어

- **피난층 종료**: 그 층에서 마지막 인원이 비상구로 빠져나간 시각(사람이 영상으로 판정, `media/vsource/cj/drill-1022/answers.json`). 16층 08:10 · 17층 03:30.
- **최종 종료**: 그 층 인원이 1층 밖으로 나간 시각. 16층 09:10 · 17층 12:45(= 녹화 끝).
- **합본**: 여러 층의 영상을 한 화면에 나란히(좌우 또는 2×2) 붙인 것. **시계가 동기**돼 있어 같은 순간의 여러 층을 함께 본다. 각 칸의 지표는 **그 층의 값**이다(건물 합산 아님).
- **점판 / 히트맵판(`_히트맵`)**: 점판은 추적된 사람을 원 관측 그대로 점으로(④ 리플레이와 같은 그림), 히트맵판은 같은 데이터를 밀도(반경 2.5 m)로 칠한다 — 몰림을 볼 때.

## 설정

- 지표: **4대 지표 통합 표시**(`demo_viz.py --metric ALL`) — 한 지표를 주인공으로 세우지 않는다.
- 임계값 **dt_hold 2.0** (배포 기본 3.0 과 다름 — 화면 좌하단에 표기). 리플레이 편집본 저장값.
- 점: **원 관측 그대로**(raw) — 각본 영상처럼 N 명으로 이어 붙이지 않는다.
- 출구 카운트: **선(line) 통과 카운트**, 복도경로. 전 세션 프레임 손실 없이(`VSOURCE_FILE_NODROP=1`) 녹화.
