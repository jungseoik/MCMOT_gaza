**추론은 한 번만** 하고(`exit_debug.py --capture`) 규칙만 바꿔 재생한다
(`exit_eval.py`) — 변형을 수십 개 재도 몇 초다.

```bash
python tools/exit_debug.py --package aihub-drill-1f3f --scenario scenario_07 \
       --capture /tmp/exit_cap/scenario_07.pkl     # 관측 캡처 (추론 1회)
python tools/exit_eval.py --caps /tmp/exit_cap      # 규칙 변형 A/B
```

## 왜 규칙 완화가 실패하는가

누락의 직접 원인은 `ZoneGate` 의 "밖에서 본 적 있는 키만 센다" 조건이다
(진단 22건). 문 앞에서 사람이 겹쳐 가려졌다 나오면 트래커가 **새 ID** 를
발급하고, 그 트랙의 첫 관측이 이미 존 안이라 영영 안 세진다.
  s07 cam9:12 는 존 안에서 29프레임(5.8초) 관측되는데 한 번도 안 세졌다.

그런데 이 조건을 풀면(③) 같은 사람의 **조각이 각각** 세져 초과가 난다.
부족 −8 이 초과 +12 로 바뀌어 순손실이다. 시공간으로 조각을 다시 묶어봐도
(④⑤) 과병합이 나서(s07 9→5) 근본 해결이 아니다.

**둘은 같은 문제의 양면이다 — 트랙렛 단위로 세기 때문이다.**
