## 왜 검정으로 덮나

화각이 매핑과 다르면 호모그래피가 엉뚱한 바닥으로 투영해 **유령 점·유령 통과**를 만든다. 검정 프레임은
검출이 0 이라 그 구간은 "관측 없음"이 된다 — 공백은 생기지만 틀린 값은 안 들어간다.

- 덮은 클립: `scenario_16F/` · `scenario_17F/` 의 cam1·cam4·cam8·cam12·cam16 (두 길이 모두). 원본은 같은 자리 `*.orig.mp4`.
  비식별 사본(`_deid/scenario_17F/`)의 cam12·cam16 도 같은 구간을 덮었다.
- 다시 만들기: 아래 구간을 ffmpeg `drawbox ... enable='…'` 로 덮는다(재인코딩 libx264 crf18).
  cam1 `lt(t,179)` · cam4 `lt(t,232)+gte(t,416)` · cam8 `lt(t,43)+gte(t,544)` · cam12 `lt(t,204)` · cam16 `lt(t,300)`
- 매니페스트 `scenarios[].data_gaps` 에도 같은 내용이 들어가 리플레이 화면에 경고로 뜬다.
