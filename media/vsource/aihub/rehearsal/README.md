## 붙는 층 · RTSP 경로

**전 시나리오(01~09) 공통 AI hub 3층** 촬영(확인 2026-09-08) → 사이트 층 **`floor4`(AI hub 3층)** 에
붙는다. 도면·구역·출구·경로는 :8900 ① 맵설정에서 관리(ADR 09 §7 빙의 모드). 도면 출처는
`AI지원센터_3F.dxf`(`cad/ai_hub_cad/target_floors/`) — CJ 가 층을 빌린 것과 같은 방식이라
① 에서 CAD·구역을 고치면 리허설 지표에 즉시 반영된다.

RTSP 경로(`path`)는 `aihub_camNN` 으로 통일 — 시나리오가 바뀌어도 같은 cam 번호는 같은 경로라
:8900 카메라는 한 번만 등록하고 **매핑도 cam 당 1회**면 된다.
