## 규칙
- 파일명은 `카메라-설치정보.md`, `시나리오-설명.md` 처럼 내용이 드러나게. 원본(pdf·xlsx·이미지)은
  그대로 두고, 요약·매핑용 정리는 `.md` 로 옆에 쓴다.
- 카메라 번호(cam01~cam18)·시나리오 번호(scenario_01~09)는 `rehearsal.json` 과 **같은 표기**를 쓴다
  (CJ 는 `cam1`~`cam14` 무패딩, AI hub 는 촬영본 파일명 그대로 **2자리 패딩**).
- 여기서 정리된 사실(카메라 층·위치·바라보는 방향)이 `rehearsal.json` 의 `cameras[].floor`·`name`
  과 어긋나면 매니페스트를 고친다 — 문서가 근거, 매니페스트가 실행값.
