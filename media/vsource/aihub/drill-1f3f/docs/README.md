# aihub/drill-1f3f/docs — 촬영·카메라 정보 문서

패키지에 딸린 **사람이 읽는 자료**를 여기 둔다 (git 추적 — 영상만 HF, 문서는 레포).
기계가 읽는 정의는 `../rehearsal.json` 이고, 이 폴더는 그 근거·설명이다.

| 파일 | 내용 |
|---|---|
| `촬영기록-및-카메라-매핑.md` | 촬영 담당 전달 문서 + 정리자 주 — 폴더 구조·싱크 방식·**도면 위치↔실카메라 매핑**·카메라별 concat 오프셋·시나리오별 구간·**이동 경로** |
| `카메라-배치도.png` | 도면 위 카메라 위치와 바라보는 방향 — **1층·3층 각각** |

## 규칙 (기존 패키지와 동일)

- 파일명은 내용이 드러나게. 원본(pdf·xlsx·이미지)은 그대로 두고 요약·정리는 `.md` 로 옆에.
- 카메라 번호·시나리오 번호는 `rehearsal.json` 과 **같은 표기**를 쓴다.
- 여기서 정리된 사실(층·위치·방향)이 `rehearsal.json` 의 `cameras[].floor`·`name` 과
  어긋나면 **매니페스트를 고친다** — 문서가 근거, 매니페스트가 실행값.
- 촬영 결손(배터리 소진 등 영상 없는 카메라)은 문서에 적고 매니페스트
  `scenarios[].data_gaps` 에도 **구조화**해 넣는다 — ⑤ 리허설 탭이 경고로 띄운다.
