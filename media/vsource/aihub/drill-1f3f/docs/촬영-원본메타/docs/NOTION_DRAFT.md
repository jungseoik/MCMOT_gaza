### 작업 흐름

1. **`02_concat`** — 원본 녹화본을 카메라별로 시간순 concat
   - 액션캠이 10분 단위로 파일을 나눌 때 **이전 파일 끝 1초를 다음 파일 앞에 중복 기록**한다.
     이음새 124곳 전부를 프레임 해시로 실측한 뒤 제거했다 (`inpoint 1.0` + `duration`).
   - **녹화 세션 분리** — cam31·32·33·38은 촬영자가 녹화를 멈췄다 다시 시작해 37~40분의
     실제 공백이 있다. 그 경계에는 중복이 없으므로 1초를 깎으면 실제 내용이 잘리고,
     그대로 이어붙이면 공백이 사라져 타임라인이 어긋난다. 파일명의 녹화 시작 시각으로
     공백을 감지해 세션별로 따로 연결했다.
2. **싱크** — 조별로 전 카메라를 모아놓고 친 **슬레이트(손뼉)** 를 기준점으로 사용
   - **손바닥이 맞닿는 프레임**을 프레임 시트에서 육안 판독해 확정
   - **오디오 손뼉 도달 시각으로 교차 검증** — 소리는 빛보다 늦게 도착하므로 영상 접촉보다
     이른 값이 나오면 판독이 틀린 것이다. 이 방법으로 60fps 카메라 3대의 판독 오차를 잡아냈다.
   - 카메라 내장 시각(번인)은 수동 설정이라 기준으로 쓰지 않았다
3. **`03_scenarios/scenario_NN`** — 오프셋 기준으로 시나리오 구간 컷
   → 시나리오별 그리드로 합쳐 동기화 육안 검증

> **컷은 `-c copy`로 하면 안 된다.** 컷 지점이 키프레임(30fps 0.5초 / 60fps 0.25초)과 맞지
> 않아 카메라마다 다른 양으로 밀려 싱크가 깨진다. 정확 탐색 + 재인코딩(libx264 crf 16)으로 처리했다.

### 60fps 카메라 판독 주의점

cam15·16·17·18·37은 60fps로 촬영됐다. 처음에 30fps 격자로 프레임 시트를 뽑아 판독했더니
접촉 순간이 건너뛴 프레임에 있는 경우 판독이 최대 1/60초 늦어졌다.

오디오 교차 검증에서 **소리가 영상보다 먼저 도착하는(물리적으로 불가능한) 값**으로 드러나,
해당 카메라만 네이티브 60fps 시트로 다시 뽑아 확정했다.

| 카메라 | 30fps 시트 판독 시 소리 도달 | 판정 |
| --- | --- | --- |
| cam15 | −2.3 ms | 불가능 → 재판독 |
| cam17 | −11.6 ms | 불가능 → 재판독 |
| cam18 | −0.2 ms | 불가능 → 재판독 |
| 정상 14대 | +39 ~ +78 ms | 정상 |
