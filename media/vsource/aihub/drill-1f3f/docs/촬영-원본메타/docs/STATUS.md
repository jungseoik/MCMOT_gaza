## 고정 제약

- `01_original/`은 SD카드 원본. **수정 금지.**
- **비디오만 납품.** 오디오는 싱크 교차검증에만 쓰고 산출물에서 제외한다.
- `-c copy`로 시나리오 절단 **금지** — GOP 경계(30fps 0.5초 / 60fps 0.25초) 때문에
  프레임 단위로 자를 수 없다. 반드시 재인코딩.
- 액션캠은 파일 분할 지점마다 **1.000초 내용 중복**을 만든다. `inpoint` + `duration`으로
  제거한다 (`inpoint`만 쓰면 0.088초 갭 발생).
- **녹화 세션 경계에는 중복이 없다.** 1초를 깎으면 실제 내용이 잘린다.
  파일명 시각으로 공백을 감지해 세션을 분리한다.
- 싱크 기준은 **손이 맞닿는 순간만**. 손 높이·얼굴 위치는 각도 때문에 부정확.
- **60fps 카메라는 네이티브 60fps로 프레임 시트를 뽑을 것.** 30fps 격자로 읽으면
  최대 1/60초 늦게 판독된다.
- 오디오 손뼉 도달은 **항상 영상 접촉보다 늦어야 한다.** 음수가 나오면 판독 오류다.
- 시나리오 구간은 **사용자가 그리드 영상을 보고 지정**한다. 자동 탐지하지 않는다.
- cam33은 비상구 카메라로 인체감지 점등. 암전이 정상이며 결함이 아니다.
- ffmpeg에 libfreetype이 없어 **`drawtext` 사용 불가** → Pillow로 합성.
- Bash 툴 셸이 zsh라 unquoted 변수가 워드 분할되지 않는다. 카메라 목록을 다루는
  스크립트는 반드시 `bash`로 실행할 것.
- macOS BSD `head`는 `head -n -1`을 지원하지 않는다.
