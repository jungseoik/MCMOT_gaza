# 00_meta — 재현용 메타데이터

2026-09-11 피난 시나리오 촬영(카메라 27대) 데이터 작업의 설정·스크립트·검증 기록.
영상 원본이 로컬에서 삭제돼도 이 폴더만 있으면 전 과정을 재현할 수 있다.

## sync/
| 파일 | 설명 |
|---|---|
| `offsets.csv` | **핵심.** 27대 통합 오프셋. `concat_time = sync_time + offset` |
| `offsets_g1.csv` | 1~18조 (18대) |
| `offsets_g2.csv` | 31~39조 (9대) |
| `scenarios.csv` | 시나리오 14개 구간 + 이동 경로순 카메라 목록 |
| `offsets_s2_cam31-38.csv` | cam31·32·33·38 2차 촬영(15:46~) 오프셋 — 이번 납품 제외분 |
| `scenarios_s2_cam31-38.csv` | 위 2차 촬영분 시나리오 4개 |

기준점: 각 조의 **슬레이트 손 맞닿는 순간 = sync 0**.
조가 다르면 타임라인도 다르다 — 1~18조와 31~39조는 서로 맞춰져 있지 않다.

## scripts/

## 주의
- `01_original/`은 SD카드 원본. 수정 금지.
- 비디오만 사용. 오디오는 납품물에 포함하지 않는다 (싱크 검증에만 사용).
- 도면 번호 = 실제 카메라 번호. 매핑 변환 불필요.
- cam19는 백업용으로 미사용 (납품 제외).
- cam33은 비상구 카메라로 인체감지 점등. 암전이 정상이며 결함이 아니다.
- `-c copy` 금지. GOP 경계(30fps 0.5초 / 60fps 0.25초) 때문에 프레임 단위 절단 불가.
- 액션캠은 파일 분할 지점마다 1.000초 내용 중복을 만든다. `inpoint` + `duration`으로 제거.
  `inpoint`만 쓰면 0.088초 갭이 생긴다.
- cam31·32·33·38은 녹화 세션이 둘로 끊겨 있다(37~40분 공백). 세션 경계에는 중복이 없다.
- 60fps 카메라는 반드시 네이티브 60fps로 프레임 시트를 뽑을 것.
