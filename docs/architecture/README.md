## 한 줄 요약

> DB는 **PostgreSQL(PostGIS+TimescaleDB+pgvector) 단일화**, 실시간은 **Redis로 시작**,
> **Kafka·DeepStream·Triton은 150ch PoC 이후** 도입. 모든 선택은 "채널 스케일"과
> "요구 2·4·5가 전부 기하 연산"이라는 두 축으로 갈린다.
