## 작성 규칙

1. **폴더 1개 = 보고서 1건.** 폴더명은 `YYYY-MM-DD_제목` 형식.
2. 폴더 구성은 아래를 따른다.
   ```
   YYYY-MM-DD_제목/
     README.md          본문 (표지표 · 개요 · 방법 · 결과 · 판정 · 한계 · 재현절차)
     img/               본문 수록 그림 (PNG)
     data/              원자료 (CSV 등) — 수치의 출처를 추적할 수 있어야 한다
   ```
3. 본문 첫머리에 **문서번호 · 작성일 · 검증범위 · 판정**을 표로 둔다.
4. **한계 및 유의사항** 절을 반드시 포함한다. 검증 범위를 벗어난 주장,
   사후 조정한 설정, 기록되지 않은 항목을 명시한다.
5. **재현 절차**를 포함한다. 제3자가 같은 결과를 얻을 수 있어야 한다.
6. 그림은 스크립트로 생성하고, 원자료 CSV 를 함께 둔다.
7. **배포본 PDF** 를 `README.pdf` 로 같은 폴더에 둔다 — 흰 배경·A4·쪽번호.
   ```bash
   python tools/md2pdf.py docs/deliverables/<폴더>/README.md
   ```
   본문을 고치면 PDF 도 다시 뽑는다(md 가 정본, PDF 는 배포본).
