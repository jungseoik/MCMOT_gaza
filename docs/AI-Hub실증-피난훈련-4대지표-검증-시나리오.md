# AI Hub 피난 시나리오 — 4대 지표 검증

약 **10명(변동 가능)** 으로 촬영해 4대 지표(IDR·EPFI·CBS·SEI)를 검증하는 시나리오.

## 공통 세팅

- 인원: 10명, **한 그룹**으로 시작
- 대피시작점 3곳 — **대피시작점 A**(비상구 A 근처), **대피시작점 B**(비상구 B 근처), **대피시작점 C**(비상구 B 근처)
- 비상구 2곳 — **비상구 A**, **비상구 B**
- 각 대피시작점에 권장 대피경로가 그려져 있음

---

## 1. IDR — 피난 반응

경보 후 각 구역이 얼마나 빨리·멀리서 피난을 개시했는지 측정.
개시 판정 **4조건(속도 · 방향정렬 · 인원비율 · 유지시간)** 을 하나씩 만족/불만족시켜 촬영.

| 시나리오 | 행동 | 결과 |
|:---:|------|------|
| **시나리오 1** | 경보 후 10명 전원이 대피경로를 따라 즉시 출발 | 4조건 만족 → **개시 판정, IDR 산출** |
| **시나리오 2** | 10명 중 **5명이 경로를 벗어나 다른 방향**으로 이동 | 방향정렬·인원비율 조건 미달 → **개시 지연·미개시** |
| **시나리오 3** | 전원 경로는 맞되 **아주 천천히** 이동 | 속도 조건(v_th) 미달 → **개시 판정 안 섬** |
| **시나리오 4** | **움직였다 멈췄다 반복**(연속 유지 안 됨) | 유지시간(Δt_hold) 미충족 → **개시 판정 리셋·지연** |

## 2. EPFI — 경로 충실도

각자가 권장 대피경로를 얼마나 충실히 따랐는지 측정.

| 시나리오 | 행동 | 결과 |
|:---:|------|------|
| **시나리오 1** | 10명 전원이 대피경로대로 이동 | 이탈 없음 → **충실도 높음** |
| **시나리오 2** | 10명 중 **4명이 경로를 벗어나 돌아서(우회)** 이동 | 4명 경로 이탈 → **충실도 낮음** |
| **시나리오 3** | 출발 후 **짐 가지러 자리로 되돌아갔다** 재출발 | 큰 이탈 → **해당 인원 충실도 0 근처** |
| **시나리오 4** | 경로에서 **살짝 벗어났다 곧 복귀** | 허용 이탈 언저리 → **중간 점수(경계 검증)** |

## 3. CBS — 병목 혼잡

비상구·통로에서 혼잡이 얼마나 오래·심하게 쌓였는지 측정.

| 시나리오 | 행동 | 결과 |
|:---:|------|------|
| **시나리오 1** | 한 비상구로 **줄 서서 순차로** 진입 | 임계밀도 미초과 → **병목 적음** |
| **시나리오 2** | 한 비상구로 **뭉쳐서 한꺼번에** 진입 | 임계밀도 초과 지속 → **병목 큼** |
| **시나리오 3** | 인원을 **두 비상구로 나눠** 진입 | 각 비상구 밀도 분산 → **병목 완화** |
| **시나리오 4** | 좁은 **중간 통로에서 두 그룹이 합류** | 통로에 일시 정체 → **통로 병목 발생** |

## 4. SEI — 비상구 분포

실제 비상구 사용이 설계 용량 분포와 얼마나 일치하는지 측정.

| 시나리오 | 행동 | 결과 |
|:---:|------|------|
| **시나리오 1** | 10명이 **7명·3명 비율**로 가까운/먼 비상구로 분산 | 용량 비율대로 분산 → **분포 일치(높음)** |
| **시나리오 2** | 10명이 **한 비상구로만** 몰림 | 다른 비상구 미사용 → **분포 불일치(낮음)** |
| **시나리오 3** | 용량 큰(넓은) 비상구 놔두고 **좁은 비상구로 몰림** | 용량과 반대로 쏠림 → **불일치 심함(더 낮음)** |
| **시나리오 4** | 일부가 비상구 **나갔다 다시 들어옴(왕복)** | 최초 통과만 집계 → **중복 카운트 방지 검증** |
