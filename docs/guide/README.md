# 사용 가이드 (허브)

MACS-EVAC의 사용자 가이드는 **3종**으로 구분된다. 무엇을 하려는지에 따라 골라 읽는다.

| 가이드 | 대상 화면 | 내용 |
|--------|-----------|------|
| **[단일영상-분석-MVP/](단일영상-분석-MVP/)** | 기존 MVP UI (`:8000`) | 비디오/RTSP 1채널을 올려 추적·속도·밀도·체류·인아웃 카운팅을 보는 화면. 소스추가→분석설정→분석화면 |
| **[멀티카메라-시스템/](멀티카메라-시스템/)** | 멀티카메라 2D맵 (`:8900`) | CCTV N대를 공통 평면도에 매핑하고 경보 세션으로 **4대 정량지표(IDR·EPFI·CBS·SEI)** 산출. 맵설정→카메라매핑→운영뷰→평가세션 |
| **[도면-편집기/](도면-편집기/)** | 도면 편집기 (`:8910`) | CAD(DWG/DXF)에서 2D맵 생성 — 문 열기 터치업·Exit 지정·피난경로 검증·열지도. [맵교체 절차](도면-편집기/맵교체.md) 별도 |

## 어디서부터?

- **처음 세팅** (새 현장): ① 도면 편집기로 CAD→맵 생성·적용 → ② 멀티카메라 가이드의
  맵설정(요소 드로잉)·카메라 매핑 → ③ 운영.
- **단일 영상 하나 분석**해보고 싶다: 단일영상-분석-MVP 가이드.
- 진입 관계: 멀티카메라 맵설정의 [CAD 도면에서 만들기] 버튼이 도면 편집기를 새 창으로 연다.
