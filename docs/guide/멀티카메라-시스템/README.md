# 멀티카메라 2D맵 시스템 — 화면별 사용 가이드 (튜토리얼)

여러 대의 CCTV(RTSP)를 등록해 **공통 2D 평면도 위에서 사람을 추적**하고,
경보 세션으로 **4대 정량지표(IDR·EPFI·CBS·SEI)** 를 산출하는 화면의 사용법입니다.
아래 스크린샷은 실제 서버(:8900, 3채널 실추적)에서 캡처했습니다.

- 접속: `http://<서버IP>:8900/` (pm2 `macs-system` 상시 기동, 재시작 `pm2 restart macs-system`)
- 기존 단일영상 분석 UI와는 **별도 서버** — 기존 UI 좌측 레일의 맵 아이콘으로도 진입
- 전체 흐름: **① 맵 설정 → ② 카메라 등록·매핑 → ③ 운영 뷰 → ④ 평가 세션(4대 지표)**
  — ①·②는 최초 1회(설정은 JSON으로 영속화, 재시작 시 자동 복원), ③·④가 평상시 화면

> 개발 문서: [설계서](../../architecture/02-멀티카메라-시스템-전환-설계.md) ·
> [계약(API)](../../../system/CONTRACT.md) · 실행: [`system/README.md`](../../../system/README.md)

## ① 맵 설정 — 평면도와 공간 요소 정의

### 1-1. 첫 화면

![맵설정 전체](img/01-맵설정-전체.png)

| 영역 | 내용 |
|------|------|
| 상단 탭 | ① 맵 설정 / ② 카메라 등록·매핑 / ③ 운영 뷰 전환 |
| 툴바 | [맵 이미지 업로드] + 드로잉 도구(이동/축척/피난경로/구역/병목/출입구/그래프) |
| 중앙 캔버스 | 평면도. **휠=줌, 드래그=팬** (모든 화면 공통) |
| 우측 패널 | 요소 목록(개수·삭제)·판정 임계값 입력·[사이트 저장] |

### 1-2. 맵 업로드 — CAD 메타로 축척 자동

![맵 업로드](img/02-맵업로드-CAD메타-자동축척.png)

- [맵 이미지 업로드]에서 평면도 PNG 선택. **cad-convert 산출물이면 `*_scale.meta.json`을
  같이 선택** → m/px 축척이 자동 설정됨(힌트에 "축척 자동 설정" 표시)
- 메타 없이 이미지만 올리면 → 다음 단계(축척 2점)로 수동 지정

### 1-3. 축척 2점 (수동)

![축척 도구](img/03-축척2점-도구.png)

- [축척 2점] 선택 → 실거리를 아는 두 지점 클릭 + 실거리(m) 입력
- 축척이 있어야 속도(m/s)·밀도(명/m²)·지표가 실단위로 계산됨 (미지정 시 해당 값 "—")

### 1-4. 공간 요소 드로잉

![구역 드로잉](img/04-구역-드로잉중.png)

| 도구 | 그리는 법 | 쓰임 |
|------|-----------|------|
| **피난경로** | 클릭으로 꼭짓점, 드래그로 자유곡선. 더블클릭/Enter 완료. **시작→끝 순서 = 피난 방향(끝점이 출구 쪽)** | 방향 정렬도·EPFI·피난개시 판정 기준 |
| **구역** | 꼭짓점 3점+ 클릭, 더블클릭 완료 (위 스크린샷 — 점선이 그리는 중) | 재실 수·밀도·IDR 단위 |
| **병목** | 구역과 동일 + 임계밀도(명/m²) 입력 | CBS(임계 초과 누적) |
| **출입구** | 통과선 2점 → 세 번째 클릭 = '안쪽' 방향 | in/out 카운트·SEI |

- 우측 목록에서 요소별 🗑 삭제. Esc = 그리기 취소. 이름 입력칸으로 라벨 지정 가능

> **피난경로가 하는 일 (예시)** — "회의실 앞→복도→비상구2"로 경로를 그렸다면:
> ① **방향 정렬도**: 각 사람의 이동 방향을 최근접 경로 구간의 진행 방향과 코사인 비교
> (경로 따라 걸으면 +1, 역방향이면 −1 — 운영 뷰 객체별 align)
> ② **피난개시 판정→IDR**: 구역 평균속도·**평균 정렬도**·동시만족 비율이 임계값을
> Δt_hold 유지한 최초 시점 = t_e,start. 경로가 없으면 "움직임"과 "피난 방향 움직임"을
> 구분할 수 없음 ③ **EPFI**: 사람↔경로 최근접거리 d(t)의 시간 적분 — 경로 위를 걸으면
> 100점, 허용이탈(d_allow) 밖으로 벗어날수록 0점에 수렴.
> 경로는 여러 개 등록 가능하며 사람마다 **세션 첫 관측 위치의 최근접 경로가 자동 배정**됨.
> 정렬도는 매 순간 **현재 위치의 최근접 경로 구간** 기준(카메라↔경로 직접 연결 아님 —
> 맵 좌표 거리로 자동). 단 최근접에 거리 상한이 없으므로 **구역마다 근처 경로를 하나씩**
> 그려주는 것을 권장.

> **구역이 하는 일 (예시)** — "사무구역A/회의실/복도끝" 3개를 그려두면:
> ① 실시간 구역별 재실·밀도 ② **IDR이 구역 단위로 판정** — "회의실: 경보 7초 후 개시
> (IDR 5.8) / 사무구역A: not_started"처럼 **어느 구역이 늦게 반응했는지** 구분
> ③ 공간그래프 노드와 연결(경보→구역 보행거리). 구역이 없으면 IDR 산출 대상이 없음.
> (병목과 차이: 병목=좁은 통로의 혼잡 누적 CBS 전용, 구역=사람 반응·점유 단위)

### 1-5. 공간그래프 (IDR용)

![공간그래프](img/05-공간그래프-드로잉.png)

- **왜 필요한가**: IDR = 거리÷반응시간의 "거리"를 벽을 무시한 직선이 아니라
  **복도를 따라 걷는 실제 거리**로 재기 위한 노드-엣지 그래프
- [그래프] 선택 → **빈 곳 클릭=노드 추가**(복도 교차점·문 위치), **노드 2회 클릭=엣지 연결**
  (연쇄 연결 지원, 같은 엣지 재클릭=제거, 노드 더블클릭=삭제)
- **안 그려도 동작** — 그래프가 없으면 직선거리 폴백으로 IDR 계산

### 1-6. 판정 임계값 + 저장

- 우측 하단 임계값(v_th 속도 · a_th 정렬도 · r_th 비율 · Δt 유지시간 · d_allow 허용이탈)
  — 피난개시 판정·EPFI에 사용, **고객 확정 전까지 조정 가능한 설정값**
- **[사이트 저장]** → `data/sites/<site>/site.json` 버전업 저장, 운영 뷰에 즉시 반영

## ② 카메라 등록·매핑 — RTSP를 도면 좌표에 연결

### 2-1. 카메라 목록·추가

![카메라 목록](img/06-카메라-목록과-추가폼.png)

- 좌측: 등록된 카메라(이름·RTSP·활성 토글·삭제). 추가 폼에 이름+RTSP 입력 → [추가]
- 추가 즉시 수신 시작(분석 fps 기본 5, 카메라별 설정 가능)

### 2-2. 카메라↔맵 대응점 매핑

![카메라 매핑](img/07-카메라-맵-대응점-매핑.png)

- 카메라 선택 → **좌: 실카메라 첫 프레임 / 우: 평면도** 나란히 표시
- **같은 지점을 좌·우에서 번갈아 4쌍 이상 클릭** (바닥 모서리·기둥 밑 등 바닥면 기준)
  → 서버가 호모그래피 산출·저장, 그 카메라의 발끝 좌표가 도면 좌표로 변환되기 시작
- [유효 ROI]: 카메라 화면에서 분석할 영역 polygon(선택) — 밖의 검출은 무시
- 저장 후 [연결 재테스트]로 프레임 갱신 가능. 카메라 1대 끝나면 다음 카메라 반복

## ③ 운영 뷰 — 평상시 실시간 화면

### 3-1. 실시간 맵과 지표

![운영뷰](img/08-운영뷰-실시간-지표.png)

| 영역 | 내용 |
|------|------|
| 좌측 | 카메라 목록 — 상태 뱃지(동작/재접속/끊김)·수신 fps·드랍 |
| 중앙 | 평면도 + **객체 점·방향 화살표(카메라별 색)** + 경로/구역/병목/출입구 오버레이. 병목 임계 초과 시 붉은 하이라이트 |
| 우측 | 실시간 지표 — 맵 위 객체 수·구역별 재실/밀도·병목·출입구 IN/OUT |
| 상단 | [🔔 경보 시작](세션) · [공간그래프] 토글 · SSE 연결 상태(LIVE) |

- 갱신은 SSE 1초. **카메라 영상은 표출하지 않음**(리소스 절약) — 원본 확인은 스냅샷으로
- RTSP가 끊기면 자동 재접속(지수 백오프), 좌측 뱃지로 상태 확인

### 3-2. 카메라 스냅샷

![스냅샷](img/09-카메라-스냅샷-팝업.png)

- 좌측 카메라 행 클릭 → **그 순간의 원본 프레임 1장** 팝업 (디버깅·화각 확인용)

## ④ 평가 세션 — 4대 정량지표 산출

### 4-1. 경보 시작

![경보 대기](img/10-경보위치-클릭대기.png)

- [🔔 경보 시작] 클릭 → "맵에서 경보 발생 위치를 클릭하세요" → **도면 위 경보 지점 클릭**
- 클릭 순간 = `t_alarm`. 맵에 🔔 마커 표시, 카운터·이력 초기화 후 세션 누적 시작

### 4-2. 4대 지표 카드 (진행 중 — 우측 패널 자동 확폭)

![4대지표 카드](img/11-세션-4대지표-카드.png)

| 카드 | 표시 내용 |
|------|-----------|
| **SEI** (출구 활용 효율) | 게이지(0~100) + 시간추이 + **출구별 실제/설계 분포 바 비교**. 통과 0명이면 "—"(insufficient data) |
| **CBS** (병목 혼잡 누적) | 총 CBS + 병목별 밀도 시간추이 스파크라인(임계 초과 구간 붉게) |
| **EPFI** (경로 충실도) | 평균(0~100) + 추이 + 객체별 분포 히스토그램 |
| **IDR** (구역 피난 반응) | 개시 구역 수 + 구역별 표(개시시각·지연초·IDR·상태 — 미개시 회색) |

- 우측 상단 [실시간] 버튼으로 기존 실시간 지표 패널과 전환 가능
- 1초 간격 타임라인으로 추이가 계속 쌓임

### 4-3. 세션 종료 → 결과

![결과 모달](img/12-세션-결과-모달.png)

- [⏹ 세션 종료] → **결과 요약 모달**: SEI·EPFI·CBS 최종값, 경보 시각·위치,
  적용 설정 버전(calibration/config), **[JSON]·[CSV] 내보내기**(성능위주설계 연계용)

![종료 후](img/13-세션종료후-카드유지.png)

- 종료 후에도 카드·타임라인 유지(결과 다시 열기·내보내기 버튼)
- 결과는 `data/sites/<site>/sessions/<세션id>.json` 자동 저장 —
  **서버를 재시작해도 유지**, `GET /api/sessions`로 이력 조회

## 자주 묻는 것

| 질문 | 답 |
|------|-----|
| 설정을 매번 다시 해야 하나 | 아니오 — 전부 JSON 영속화, 재시작 시 카메라까지 자동 기동 |
| 카메라 영상은 어디서 보나 | 운영 뷰 카메라 행 클릭(스냅샷). 연속 영상 표출은 의도적으로 없음 |
| 같은 사람이 맵에 2점으로 보임 | 중첩 화각에서 카메라별 ID가 각각 찍히는 알려진 한계(글로벌 ID 병합은 최종 단계 로드맵) |
| 속도·밀도가 "—" | 맵 축척 미지정 — ①-2/①-3으로 축척 설정 |
| SEI가 "—" | 세션 중 출구 통과 0명이거나 출구 설계인원 미입력(insufficient_data 처리) |
| 지표 값이 이상하게 큼/작음 | 카메라 매핑(대응점)이 부정확하면 좌표·속도가 왜곡 — ②-2에서 재매핑 |
