# 기존 운영 맵을 CAD 도면으로 교체하기 (실측 스크린샷)

이미 운영 중인 사이트의 2D맵을 **도면 편집기에서 만든 CAD 산출 맵으로 교체**하는
절차. 아래 스크린샷은 실제 운영 웹(:8900)에서 교체 → 자동 반영까지 실측한 화면이다.

> 편집기 자체 사용법(문 열기·Exit·검증·열지도)은 **[README.md](README.md)** 참조.
> 이 문서는 "교체가 일어나면 무엇이 어떻게 바뀌는가"에 집중한다.
>
> 🏢 **다중 도면(N개 층)**: 교체는 **맵설정에서 현재 선택된 층**에만 적용된다.
> 아래 화면은 default(17F) 층 기준. 다른 층(예: 18F)을 교체하려면 상단 층 셀렉터에서
> 그 층을 먼저 선택한 뒤 편집기를 연다 — 그 층 맵(`map_<층id>.png`)만 바뀌고 나머지 층은
> 그대로다. (README §1·§6 참조)

## 절차 (4단계, 새로고침 불필요)

### 1️⃣ 교체 전 — 기존 맵 확인

![기존맵](img/도면편집기-교체-01-기존맵.png)

맵 설정 화면. 기존 맵(여기선 17F 평면도)과 그 위에 그려둔 요소들(피난경로·구역·병목·
출입구)이 보인다. 툴바의 **[CAD 도면에서 만들기]** 클릭 → 편집기 새 창.

### 2️⃣ 편집기에서 새 도면 준비

![편집기](img/도면편집기-교체-02-편집기-열지도.png)

DWG/DXF 업로드 → (필요시) 문 열기·삭제 → Exit 지정 → 열지도/worst-N으로 확인.
버튼 경유로 열렸으므로 **"운영 서버 즉시 반영"이 기본 체크**되어 있다 —
파일만 저장하고 싶으면 해제.

### 3️⃣ [저장 & 적용]

![적용완료](img/도면편집기-교체-03-적용완료.png)

적용 결과에 저장 경로·**자동 축척(m/px)**·worst 거리·"운영서버 반영 완료"가 표시된다.

### 4️⃣ 교체 후 — 메인 화면 자동 갱신

![교체후](img/도면편집기-교체-04-교체후-자동갱신.png)

편집기 창이 보낸 신호를 받아 **맵 설정 화면이 자동으로 새 맵을 로드**한다
(힌트: "도면 편집기 적용 완료 — 맵·축척(m/px)이 자동 반영되었습니다").

## 교체되면 무엇이 바뀌나 (실측 결과)

| 항목 | 교체 후 |
|------|---------|
| **맵 이미지** (`map.png` / 층별 `map_<층id>.png`) | ✅ 새 CAD 산출 맵으로 **교체** (현재 선택된 층에만) |
| **축척** | ✅ `m_per_px` **자동 기입** (CAD가 mm 단위 — 축척 2점 수동 지정 불필요) |
| **피난경로** (routes) | ✅ **CAD 최단경로(worst-N)로 자동 재세팅** (`auto-evac-*`). 손으로 그린 경로는 보존 |
| **출입구** (exits) | ✅ 편집기 Exit → **통과선으로 자동 반영** (붉은 선. 안쪽 방향 자동 추정) |
| **구역·병목** (zones·bottlenecks) | ✅ **자동으로 비워짐(clear)** — 새 맵 위에 다시 그려야 함 |
| 카메라 등록·매핑 | ⚠ 유지되나 대응점은 이전 이미지 px 기준 — 구도가 다르면 재매핑 필요 |
| `evac_distfield.npz` / `floor_<층id>.json` | ✅ 새로 저장 (실시간 피난거리 조회용) |

### 자동 재세팅 (v1.9, `PUT /api/site/floor-elements`)

편집기 [저장 & 적용]은 **CAD 도면 기준으로 그 층 공간요소를 재세팅**한다:
- **피난경로·출입구**는 편집기가 아는 정보(최단경로 알고리즘·Exit)라 **자동 반영**된다.
- **구역·병목**은 편집기가 모르는 개념이라 **자동으로 비운다** — 옛 좌표가 새 맵과 안 맞아
  혼동을 주므로 남기지 않는다.

**따라서 교체 후 남은 일:**
1. **구역·병목을 새 맵 위에 다시 드로잉** (IDR·CBS 지표용 — 비워졌으므로 필수)
2. 자동 반영된 피난경로·출입구는 확인 후 필요시 손질 (출입구 안쪽 방향·설계인원 등)
3. 카메라↔맵 대응점은 구도가 바뀌었으면 재매핑
4. [사이트 저장]

> **다중 도면(N층)**: 교체는 **맵설정에서 현재 선택된 층**에만 적용된다. 다른 층은
> 그대로. 18F를 교체하려면 상단 층 셀렉터에서 그 층을 먼저 선택하고 편집기를 연다.

### 되돌리기 (실수로 교체했을 때)

교체는 맵 이미지뿐 아니라 **경로·출입구 재세팅 + 구역·병목 clear**까지 하므로,
[맵 이미지 업로드]로 옛 이미지만 다시 올려도 **비워진 구역·병목은 복구되지 않는다.**
완전 복원은 `data/sites/<site>/` 백업(`site.json` + `map*.png`)에서 되돌리는 것이
확실하다. → **교체 전 사이트 백업 권장**(`cp -rp data/sites/<site> /tmp/backup`).
운영 중 사이트라면 편집기 [저장 & 적용]의 "운영 서버 즉시 반영"을 끄고 파일만
저장해 확인 후 반영하는 것이 안전하다.
