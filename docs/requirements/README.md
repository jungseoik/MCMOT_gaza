# Requirements · 북극성 요구사항

MACS-EVAC 분석 엔진이 **무엇을 추출·산출해야 하는가**를 정의하는 원천 요구사항 문서 모음.
기능 설계·우선순위·완료 판정이 흔들릴 때 가장 먼저 돌아오는 기준.

## 문서

1. ⭐ **[삼성화재-피난훈련-정량평가-4대지표-요구사항.md](삼성화재-피난훈련-정량평가-4대지표-요구사항.md)**
   — 프로젝트의 **최상위 목표**. 4대 정량지표(**IDR·EPFI·CBS·SEI**)의 정의·입력·수식·출력·
   레포 현황·확정 필요 항목. 인터뷰로 확정된 설계 결정(카메라 스코프·권장경로 입력 분기·
   그리드↔구역·임계값·SEI 단위·대시보드 모드) 포함.
2. **[CCTV-영상분석-엔진-필수추출정보.md](CCTV-영상분석-엔진-필수추출정보.md)**
   — 4대 지표 계산의 **기반(base)** 이 되는 **5개 정보 카테고리**(객체 추적 / 평면도 좌표 /
   이동속도·방향 / 구역 밀도 / 시간 이벤트). 현재 단일채널 기준 대부분 충족.

## 한 줄 요약

> **기반(5대 카테고리)**: 픽셀 검출·추적(1) → 도면 좌표 변환(2) → 속도·밀도(3·4) → 피난 개시·통과 이벤트(5).
> **목표(4대 지표)**: 그 산출물 위에서 **IDR**(구역 반응 확산) · **EPFI**(경로 충실도) ·
> **CBS**(병목 혼잡 누적) · **SEI**(비상구 활용 효율)를 계산한다.
> 5대 카테고리는 반드시 충족해야 할 base, 4대 지표가 이 프로젝트의 궁극 산출물.
> **단, Multi-Camera ID 병합은 전체에서 가장 마지막 — 그 전까지는 카메라별 ID 유지로 동작한다.**
