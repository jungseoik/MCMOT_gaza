# Requirements · 북극성 요구사항

MACS-EVAC 분석 엔진이 **무엇을 추출해야 하는가**를 정의하는 원천 요구사항 문서 모음.
기능 설계·우선순위·완료 판정이 흔들릴 때 가장 먼저 돌아오는 기준.

## 문서

1. **[CCTV-영상분석-엔진-필수추출정보.md](CCTV-영상분석-엔진-필수추출정보.md)**
   — 분석 엔진이 추출해야 할 **5개 정보 카테고리**(객체 추적 / 평면도 좌표 /
   이동속도·방향 / 구역 밀도 / 시간 이벤트)와 각 항목의 정의·의존 관계.

## 한 줄 요약

> 픽셀 검출·추적(1) → 도면 좌표 변환(2) → 속도·밀도(3·4) → 피난 개시·통과 이벤트(5).
> 모든 기능은 이 5단계 정보 사슬 위의 어딘가를 채우는 일이다.
> **단, Multi-Camera ID 병합은 전체에서 가장 마지막 — 그 전까지는 단일 카메라 기준으로 동작한다.**
