# 삼성화재 피난훈련 정량평가 — 4대 정량지표 요구사항 (North Star v0.1)

> 본 문서는 MACS-EVAC 프로젝트의 **최상위 목표 요구사항**이다.
> 기존 [CCTV 영상분석 엔진 필수추출정보(5대 카테고리)](CCTV-영상분석-엔진-필수추출정보.md)는
> **반드시 충족해야 하는 기반(base)** 이며 현재 단일채널 기준으로 대부분 충족되어 있다.
> 이제 프로젝트의 궁극 산출물은 그 위에서 계산되는 **4대 정량지표(IDR·EPFI·CBS·SEI)** 이다.
> 기능의 "왜 필요한가 / 무엇을 최종 산출하는가"가 흐려질 때 가장 먼저 돌아올 기준 문서.

- 원천 스펙: 삼성화재 피난훈련 정량평가 시스템 1-Page 요구사항 명세서 v0.1
- 관계: **5대 카테고리(기반) → 4대 지표(목표)**. 5대 카테고리의 산출물(글로벌 궤적·도면좌표·속도·밀도·통과이벤트)이 4대 지표 계산의 **입력**이 된다.

원천 스펙 §6("구현 전 확정 필요 항목")을 우리 레포 현황 기준으로 인터뷰하여 아래와 같이 확정했다.
남은 미확정(고객 확정 필요) 항목은 [§9](#9-확정-필요-항목-고객추후)에 별도 정리한다.

| # | 항목 | 확정 내용 |
|---|------|-----------|
| D-1 | **카메라 스코프** | 멀티카메라 **입력**을 받되, **현재는 각 카메라 내부 local ID만 유지**한다. 카메라 간 글로벌 ID 병합은 **최종 단계 과제**(기존 5대 카테고리 방침과 동일). 단, 데이터 계약에는 `global_track_id` 필드를 **미리 둔다**(단일카메라 구간에서는 `global_track_id = local_track_id`). |
| D-2 | **권장 피난 경로 입력** | **두 개의 입력 분기.** ① **수동**: 관리자가 평면도 이미지를 줌인/줌아웃하며 **자유곡선 화살표(polyline)** 를 그려 등록. ② **CAD API 연동**: 도면에서 최적 방향·전체 경로를 자동 산출해 전달. 어느 경우든 경로는 **CAD가 제공하는 정사각형 그리드 셀 단위 대표 방향벡터 field** 로 이산화된다. |
| D-3 | **EPFI 계산 방식** | 스펙 원문대로 **경로까지 최근접거리의 시간 적분**. 대피경로 선분(polyline)을 맵에 표출하고, 호모그래피로 맵에 투영된 각 ID의 시간별 위치가 경로에서 벗어난 거리 `d_i(t)`를 적분한다. (그리드 대표벡터는 EPFI가 아니라 **FR-03 피난개시 방향정렬도** 판정에 사용) |
| D-4 | **구역 ↔ 그리드 관계** | **독립 레이어.** 밀도·병목용 구역 polygon은 CAD 2D 맵 위에 **별도로 지정·계산**된다. 단 모든 좌표·관리는 **전체 2D 매핑 좌표계**를 공유한다(그리드 셀 = 경로 방향벡터용, 구역 polygon = IDR·밀도·병목용). |
| D-5 | **구역/공간 그래프 정의** | 평면도 위 **수동 polygon** + **수동 노드그래프**(경보 위치→구역 최단거리용). config로 버전관리. |
| D-6 | **판정 임계값** | 모든 임계값(`v_th, a_th, r_th, Δt_hold, d_allow, ρcrit, w_k` 등)은 **UI에서 관계자가 입력**한다. **임의 디폴트값**을 제공하되 **고객 확정이 필요한 값**이다(하드코딩 금지, 버전관리 config). |
| D-7 | **SEI 설계용량 단위** | `C_j,design` = 비상구별 **설계 총인원(명)**. **사람이 입력**(디폴트 존재, 지정 시 값 명시). 평가 시간창 = **실제 이동이 관측된 구간**(경보~평가종료). |
| D-8 | **종합점수/등급** | **본 문서 범위에서 제외.** 4대 지표는 개별 산출까지만. 종합점수·A/B/C 등급·가중치는 고객이 승인한 기준 확정 후 별도 반영. |
| D-9 | **대시보드 모드** | **실시간 + 녹화본 재생** 모두 지원. 데이터 갱신 주기 기본 **5초**(설정 가능). |
| D-10 | **설정 영속화** | 좌표계·그리드·경로·구역·그래프·임계값·비상구 용량은 코드에 하드코딩하지 않고 **버전 관리 가능한 설정 데이터(JSON)** 로 저장한다. |

## 1. 시스템 목적 및 처리 흐름

다중 CCTV에서 검출·추적된 사람의 이동 궤적을 건물 2D 평면도 좌표로 통합하고,
경보 발생 이후의 피난 행동을 분석하여 **IDR / EPFI / CBS / SEI** 4개 정량지표를 산출한다.
결과는 평면도 기반 대시보드, 평가 리포트, 성능위주설계(PBD) 시뮬레이션 입력으로 제공한다.

```
영상/트랙 입력(멀티카메라)
  → 카메라 시간 동기화(정규화)
  → 영상좌표(발위치 하단중심) → 호모그래피 → 평면도 2D 좌표
  → 카메라 내부 궤적 생성 (global_track_id 필드 보유, 병합은 최종단계)
  → 구역·경로·병목·출구 이벤트 판정
  → 4대 지표(IDR·EPFI·CBS·SEI) 산출
  → DB/API 저장
  → 대시보드(실시간·재생) · PBD 시뮬레이션 연계
```

## 2. 4대 지표 상세

> 각 지표는 **독립 파일**로 관리한다. 아래는 요약 + 링크.
> 전체 수식·구현 현황·시각화는 각 지표 파일에서 확인.

### 2.1 IDR — 구역별 피난 반응 확산 지표 (FR-03 · FR-04)

📄 **[IDR-피난반응확산지표.md](IDR-피난반응확산지표.md)**

- **목적**: 경보 이후 각 구역이 얼마나 빨리, 얼마나 멀리서 피난을 개시했는지 정량화.
- **핵심 수식**: `IDR_e = D(e, S_origin) / max(t_e,start − t_alarm, ε)` [m/s]
- **개시 판정**: v_e·a_e·r_e 세 조건이 Δt_hold 이상 연속 유지되는 최초 시각 → `t_e,start`
- **현황**: 전체 구현 완료. 그리드 벡터 field → Route polyline tangent 대체 중.

### 2.2 EPFI — 권장 경로 대비 실제 이동 경로 충실도 (FR-05)

📄 **[EPFI-경로충실도지표.md](EPFI-경로충실도지표.md)**

- **목적**: 각 사람이 권장 대피경로를 얼마나 충실히 따랐는지 0~100 점수로 정량화.
- **핵심 수식**: `EPFI_i = max(0, 1 − ∫d_i(t)dt / (T_i × d_allow)) × 100`
- **전체 지표**: `EPFI = (1/n) Σ EPFI_i` (유효 객체 평균)
- **현황**: 전체 구현 완료. d_i(t) 시계열 저장·개별 차트 포함.

### 2.3 CBS — 병목 구역 혼잡 누적 지표 (FR-06)

📄 **[CBS-병목혼잡누적지표.md](CBS-병목혼잡누적지표.md)**

- **목적**: 병목 구역에서 임계밀도 초과 혼잡이 얼마나 오래·심하게 누적됐는지 정량화.
- **핵심 수식**: `CBS = Σ_k ∫ max(0, ρ_k(t) − ρcrit,k) · w_k dt`
- **현황**: 전체 구현 완료. 병목별 rho_crit·weight UI 인라인 편집 포함.

### 2.4 SEI — 비상구 공간 활용 효율성 지표 (FR-07)

📄 **[SEI-비상구활용효율지표.md](SEI-비상구활용효율지표.md)**

- **목적**: 실제 출구 사용 분포와 설계 통과용량 분포의 일치도를 L1 거리로 정량화.
- **핵심 수식**: `SEI = (1 − ½Σ|P_j,actual − P_j,design|) × 100`  (TVD 정규화)
- **현황**: 전체 구현 완료. 그룹 바차트 + 출구별 Δ 행 시각화 포함.

## 3. 필수 입력 데이터

| 구분 | 필수 데이터 |
|------|-------------|
| 평가 세션 | `session_id`, 경보 시각 `t_alarm`, 경보 발생 위치, 평가 시작·종료 시각, 예상 참여 인원 |
| 카메라 보정 | `camera_id`, 영상 해상도, 왜곡 보정값, 영상 기준점 ≥4, 평면도 대응 좌표, Homography 행렬, 유효 촬영 영역 |
| 객체 트랙 | `timestamp`, `camera_id`, `local_track_id`, `global_track_id`(현재 = local), bbox, 발위치 `(u,v)`(bbox 하단중심), confidence |
| 공간 정보 | 평면도 좌표계·축척, 이동가능 공간, 구역 polygon, 공간 노드그래프, 출입구·계단·비상구 위치, 권장경로 polyline, **그리드 셀 대표벡터 field** |
| 병목 정보 | 병목 후보영역 polygon, 면적 `A_k`, 임계밀도 `ρcrit,k`, 가중치 `w_k` |
| 비상구 정보 | 비상구별 가상 통과선, 통과 방향, 설계 총인원 `C_j,design`(사람 입력) |
| 판정 파라미터 | `v_th, a_th, r_th, Δt_hold, d_allow, ρcrit,k, w_k`, 평가 시간창 (UI 입력·config, 디폴트 제공) |

> 모든 공간 좌표·구역·경로·임계값은 하드코딩하지 않고 **버전 관리 가능한 설정 데이터(JSON)** 로 저장한다(D-10).

```text
EvaluationResult

- config_version
```

## 5. 대시보드 요구 (FR-08)

- 2D 평면도 위에 실제 궤적·현재 위치·권장 경로·병목 영역·혼잡 구역·비상구 표시.
- 구역별 IDR, 객체별·전체 EPFI, 병목별 CBS, SEI 및 시간 추이.
- 병목 구간 표, 출구별 실제·설계 통과량 비교, 경고·개선 권고.
- **실시간 + 녹화본 재생** 모두 지원(D-9), 갱신 주기 기본 5초(설정 가능).

## 8. 개발 완료 기준 (검증)

- **결정성**: 동일 입력·동일 설정 버전 → 항상 동일 결과.
- **역추적성**: 모든 지표는 최종 점수에서 원본 트랙 포인트·적용 파라미터까지 역추적 가능.
- **좌표 품질**: 카메라별 좌표변환 오차·유효영역 밖 객체 비율 확인 가능.
- **합성 자동 테스트**:
  - 권장 경로를 완전히 따른 궤적 → `EPFI = 100`
  - 임계밀도 미초과 → `CBS = 0`
  - 실제 출구 분포 = 설계 분포 → `SEI = 100`
  - 피난개시 조건이 정확히 유지시간 충족하는 데이터 → 예상 시각에 `t_e,start` 발생
- **예외 처리 명시**: 카메라 누락, ID 변경, 트랙 단절, 출구 왕복 통과, 경로 미배정, 실제 통과 0명(`insufficient_data`).
- **종합점수 분리**: 종합점수·A/B/C 등급은 개별 지표와 분리(D-8), 고객 승인 가중치 확정 후 적용.

## 9. 확정 필요 항목 (고객/추후)

인터뷰로 방식은 확정했으나, **구체 값·형식·정확도 목표**는 고객 확정이 필요하다.

1. **임계값 실제 기준치**: `v_th, a_th, r_th, Δt_hold, d_allow, ρcrit,k, w_k` (디폴트는 임의 설정, 고객 확정 필요 — D-6).
2. **CAD API 연동 형식**: 권장경로 자동산출(입력 분기 ②)의 실제 데이터 형식·프로토콜 (D-2).
3. **글로벌 ID 병합 아키텍처 시점**: 지금은 카메라별 local ID. 병합 도입 시점·정확도 목표·시간동기 허용오차·좌표변환 허용오차 (D-1).
4. **SEI 설계 총인원 값**: 비상구별 `C_j,design` 실제 값(사람이 입력) 및 평가 시간창 확정 (D-7).
5. **구역 분할·그래프 구체안**: 구역 개수·경계·노드그래프 연결 정의(수동), 그리드 셀 크기 (D-4·D-5).
6. **종합점수 가중치·등급 기준·개선 권고 규칙** (D-8).

> **핵심**: 개발 대상은 단순 검출 모델이 아니라
> `공통 공간 좌표계 + (카메라별) 궤적 + 이벤트 판정 엔진 + 4대 지표 계산 엔진 + 설정·검증 가능한 대시보드`
> 로 구성된 **피난 평가 데이터 시스템**이다.
