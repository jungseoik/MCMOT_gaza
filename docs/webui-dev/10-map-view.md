# 10 · 2D 맵 뷰 (top-down)

분석 화면에서 **영상 ↔ 맵**을 토글하면, 빈 흰 평면에 각 사람을 **점 + 방향벡터**로
top-down으로 표시한다. 호모그래피(ROI 실측/Depth)를 그대로 재활용한다.

## 무엇을 그리나

- **점**: 각 사람의 **발끝(접지점)** 을 지면 좌표로 변환한 위치. (bbox 가운데가 아니라
  발끝 — 높이 때문에 가운데를 쓰면 지면 위치가 뒤로 밀림)
- **방향벡터**: 최근 1초 이동의 단위 방향을 작은 화살표로(살짝). 색은 기본 ID별.
- **(정렬도 활성 시) 정렬도 오버레이** — 객체 화살표를 **정렬색**(녹=정렬/황=가로질러/적=역류)으로,
  군중 무게중심에서 뻗는 **긴 "기준 방향" 벡터**를 그린다. opt-in → [13-alignment](13-alignment.md).
- **흰 평면 + 범위 사각형**. (정합 안 한 경우)
- **(지도 정합 모드) 업로드한 실제 지도 이미지를 배경**으로 깔고 그 위에 점·방향. `m.map_image`가 true면 `drawMap`이 배경을 지도 이미지로 그림 → [14-map-registration](14-map-registration.md).

## 좌표·범위

| 보정 | 맵 좌표 | 범위(map_bounds) |
|------|---------|------------------|
| ROI 실측 / Depth (호모그래피 O) | **지면 미터** (`_world(발끝)`) — 진짜 top-down | ROI 4점을 지면으로 매핑한 사각형(안정) |
| 보정선 / 없음 (호모그래피 X) | 발끝 **이미지 픽셀** (원근 왜곡 폴백) | 프레임 크기, 또는 점들 자동 맞춤 |

`map_metric` 플래그로 진짜 미터 top-down인지 표시. 미터 모드여야 맵이 의미 있고,
보정 없으면 "이미지 평면" 산점도로 폴백(라벨 표시).

## 데이터 (백엔드 → 프론트)

`metrics.objects[i]`에 맵용 필드 추가 — `webui/speed.py`:

```python
{"id", "speed", "dwell",
 "mx", "my",        # 맵 위치 (지면 m 또는 이미지 px)
 "dirx", "diry",    # 단위 방향 (최근 1초 이동)
 "align"}           # 정렬도(코사인 -1~+1), 정렬 비활성 시 null
# metrics 상위: "map_metric"(bool), "map_bounds"([x0,y0,x1,y1] or null),
#               "has_align"(bool), "ref_dir"([dx,dy] or null)
```

`_obj_map(tid)`가 윈도우 처음↔끝 발끝을 (호모그래피면) 지면으로 변환해 위치·방향을 산출.
`_map_bounds()`는 ROI 4점을 지면으로 매핑해 안정된 범위를 만든다.

## 프론트 (`webui/index.html`)

- `.videobox` 안에 `<canvas id="mapCanvas">`(흰 배경, 기본 숨김) + HUD에 **영상/맵 토글**.
- `drawMap(m)`: 범위→캔버스 스케일, 점(ID색)·화살표(방향+화살촉)·범위 사각형 렌더.
  정렬도 활성 시 화살표를 정렬색으로 + 군중 무게중심에서 긴 "기준 방향" 벡터를 그린다.
- 영상 concat 도구용 동일 렌더러: `webui/map_render.py`(서버사이드, drawMap의 Python 포팅).
- `renderDash`가 매 갱신마다 `lastMetrics` 저장 후 맵이 켜져 있으면 `drawMap` 호출 →
  영상·대시보드와 같은 박자로 갱신(라이브 폴링/파일 재생 프레임 동기).

## 리소스 영향 (측정)

- **토글(보기 전환)**: 프론트 전용 → 추론 fps 영향 **0**. 새 영상 스트림이 아니라 좌표
  JSON으로 클라이언트가 그림 → 추가 인코딩/대역폭 거의 없음.
- **맵 데이터 계산(백엔드)**: `metrics()`에 항상 포함(재생 동기화용). 실측 **50명 0.237ms /
  프레임 ≈ 추론(60ms)의 0.4%**. 사실상 무시 가능.

## 한계 / 향후

- 박스 흔들림 → 점이 약간 떨림. 위치 스무딩(EMA) 추가 가능(미구현).
- 호모그래피 없으면 진짜 top-down 아님(이미지 평면).
- **실제 도면 오버레이**(도면 이미지 + 지면↔도면 정렬), 궤적(trail), 히트맵, 통과 카운트는
  향후 과제로 남김.
