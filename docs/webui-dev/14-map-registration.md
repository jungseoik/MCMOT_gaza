# 14. 지도 정합 (2D Map Registration)

CCTV 영상과 **실제 지도(평면도) 이미지**를 점 대응(호모그래피)으로 정합해, 사람 위치를
**지도 좌표로 변환·표시**하는 분석 모드. 요구사항 카테고리 2(평면도 좌표)·보고서 **G1(도면 정합)**
을 수동 N점 방식으로 충족한다. 정렬도·in/out 카운팅을 **선택 애드온**으로 함께 띄울 수 있다.

## 한 줄 정의
> CCTV N점 ↔ 지도 N점 대응 → **호모그래피 H(CCTV px → 지도 px)**. 사람 **발끝**을 H로 변환해
> 업로드한 지도 위에 표시. 지도 축척(m/px)으로 속도를 **km/h** 환산.

## 동작 원리
- **필터(누가)**: 찍은 N점이 CCTV 위 **ROI 다각형**. 발끝이 그 안(`pointPolygonTest`, CCTV 이미지 좌표)일 때만 측정·표시. 밖은 제외(외삽이라 부정확 + 관심영역 아님).
- **변환(어디에)**: 발끝(CCTV px) → `H` → 지도 px → 지도 위 점. (`speed.py` `_world`, `_obj_map`)
- **속도**: 지도 px 이동 × `m/px`(축척) × 3.6 → km/h. (`units_per_px`)
- **밀도**: CCTV ROI → 지도 px 폴리곤 면적 × `(m/px)²` → m². 레벨(여유/보통/혼잡) 동일.
- **정렬도(선택)**: 기준 화살표를 **지도 위에** 그림 → 이미 지도 좌표계라 변환 없이 코사인(`reference_vec_is_world`).
- **in/out(선택)**: **CCTV 위 통과선**(LineCounter, 이미지 좌표)으로 교차 카운트. 속도/밀도와 **동시 실행**.

## 유저 플로우 (화면2)
1. "속도/밀도" → 보정 **"지도 정합(N점)"** 선택 → 하단 지도 패널.
2. **지도 이미지 업로드** + **점 개수 N**(기본 10).
3. **① CCTV 점**: 위 CCTV 첫프레임에 **바닥 지점** N개 순서대로.
4. **② 지도 점**: 지도 캔버스에 **같은 순서** N개.
5. **③ 축척(2점)**: 지도에서 거리 아는 2점 + **실거리(m)**.
6. **④ 정렬방향(선택)**: 지도에 출구 방향 꼬리→머리 2점.
7. **⑤ 통과선(선택)**: CCTV에 선 2점 + 안쪽 1점.
8. **측정 시작** → 게이트: CCTV N ✓ · 지도 N ✓ · 축척 ✓ (④⑤는 선택).

## 표출 (화면3)
- 🗺 맵 토글 → **업로드 지도 배경** + 사람 발끝점·방향화살표(정렬 시 정렬색) + 정렬 기준 벡터.
- 대시보드: 속도·밀도·체류 + **정렬도 카드**(④ 시) + **In/Out·재실 카드**(⑤ 시, 재실 음수면 경보).
- 좌 영상: ID 박스·속도 + (⑤) 통과선·IN 화살표·IN/OUT 바.

## 좌표·축척 (방법 A)
- 모든 위치는 **지도 px**(H 출력). 실거리는 `m/px = 실거리 / 두_축척점_지도px거리`.
- 전제: 점은 **바닥(같은 평면)**, 지도는 **정사영 top-down**(픽셀 정방형 → m/px 스칼라 1개).

## 데이터 (서버가 받는 것) — `/start` `mode:"map"`
`cctv_pts[N], map_pts[N]`(원본 px), `map_w/map_h`, `scale_px`+`scale_m`,
선택 `align_vec_map`(지도 px), `count_addon:{line,inside,segment}`(CCTV px).
※ 지도 **이미지는 클라이언트가 보관·렌더** — 서버는 점·축척만 받아 `findHomography`로 H 계산.

## 한계 (MVP)
- 단일 구역(다각형 1개)·단일 통과선·단일 기준벡터. 다구역/다비상구는 추후(G5).
- 정합 정확도는 **점들이 감싸는 영역 안(보간)** 에서 최적. 재투영 오차 프리뷰는 미구현.
- 비정사영/왜곡 지도면 위치별 축척이 달라져 부정확(정사영 평면도 권장).

## 관련 요구사항
- 카테고리 2 **평면도 좌표** + 보고서 **G1 도면 정합** → 수동 N점 정합으로 충족.
- 카테고리 3 정렬도(④), 4 밀도, 5 통과 카운팅(⑤)을 지도 좌표 위에서 함께 산출.
