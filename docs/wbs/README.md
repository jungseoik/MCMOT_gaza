# WBS · 난이도 분석 (경영 보고용)

MACS 4대 기능을 **배포 규모(단일/15채널/50~60채널)** 별로 난이도를 평가하고,
**6~9월 4개월 개발 일정(WBS)** 으로 분해한 C레벨 보고 문서.

> 🔻 **목표 재조정(2026-07-4주차)**: 최종 채널 스케일 **150채널 → 50~60채널**로 하향(사유=실증
> 대상 규모 재산정). GPU 산정 ~8장 → **3~4장**(1GPU 16ch@5fps 실측 기반). 01·03 문서는
> 2026-06-07 시점 분석(150ch 기준 실측·외삽)이라 본문은 당시 기록으로 보존하고 상단 배너로 갱신.

## 한 줄 요약

> 기능을 "만드는 것"은 대부분 쉽다(단일 기준 F1·F2 완료급). 시수·리스크의 핵심은
> **① 50~60채널 실시간화(지연·경량화·GPU 리소스) ② F3 다카메라 융합 ③ F2 정확도(드리프트)**.
> 6~7월에 기능 데모를 당기고, 8~9월은 50~60채널 스케일·실증에 집중한다.
