## 2. ⚠️ 검출 공정성 — 왜 imgsz=1600·conf=0.1 인가

ultralytics 기본값(imgsz=640, conf=0.25)으로 돌리면 **사람이 거의 안 잡힌다.** `probe_det.py`로 sample1 프레임당 검출 수를 직접 셈:

| YOLO26m 설정 | 사람/프레임(평균) | max_det 도달 | 비고 |
|------|:----------------:|:-----------:|------|
| conf=0.25, imgsz=640 (ultralytics 기본) | **11.2** | 0 프레임 | 심하게 과소검출 → **불공정** |
| conf=0.1, imgsz=640 | 28.1 | 0 | |
| conf=0.1, imgsz=1280 | 55.9 | 0 | |
| **conf=0.1, imgsz=1600 (채택)** | **66.5** | 0 | YOLOX-X와 동급 |
| **(현재) YOLOX-X @896×1600, det 0.4** | **56.6** | — | 기준 |

- **`max_det=300`은 원인이 아니다** — 사람이 최대 76명이라 캡에 0회 도달.
- 진짜 원인은 **conf=0.25(너무 높음) + imgsz=640(너무 작음)**. → 이하 모든 수치는 **공정 조건(imgsz=1600, conf=0.1)** 기준이며, 검출 "수"가 YOLOX-X와 맞춰진 상태다.

## 4. ⭐ 다채널 처리량 (공정 조건, 단일 GPU, 프로세스=채널)

| 조합 | 1ch | 4ch 총 | 8ch 총 | per-GPU 현재 대비 |
|------|:---:|:------:|:------:|:----------------:|
| **YOLO26m + ByteTrack** | 56.8 | 97.9 | **112.8** | **×2.2** |
| YOLO26m + BoT-SORT | 37.5 | 77.9 | 98.3 | ×1.9 |
| YOLO26l + ByteTrack | 52.3 | 81.2 | 93.2 | ×1.8 |
| YOLO26l + BoT-SORT | 34.2 | 67.2 | 84.2 | ×1.6 |
| **(현재) YOLOX-X+BoostTrack** | 12.4 | 34.6 | **51.2** | ×1.0 |

> 검출 "수"를 맞추니 이득이 **불공정 640의 ×4.4 → 공정 ×2.2로 반감**. 그래도 경량검출(99M→22M)+ReID제거로 **per-GPU ~2.2배**는 유효.

## 5. 150채널 GPU 수에 미치는 영향 (공정 8ch per-GPU 외삽)

| 구성 | per-GPU | 150ch@5fps(750) | 150ch@10fps(1500) |
|------|:-------:|:---------------:|:-----------------:|
| YOLOX-X+BoostTrack(현재) | ~51 | **~15장** | ~29장 |
| YOLO26m+BoT-SORT | ~98 | ~8장 | ~15장 |
| **YOLO26m+ByteTrack** | ~113 | **~7장** | **~13장** |

> 공정 비교 시 150ch@5fps = **15장 → 약 7장**(절반). ×4.4가 아니라 ×2.2이므로 "3~4장"은 과대였고 **~7장이 현실치**. MPS·해상도 미세조정·도메인 경량모델을 더하면 추가 감소 여지.

## 6. 핵심 결론 & 트레이드오프

- **공정 비교(검출 수 동급)에서 YOLO26m+ByteTrack은 현재 대비 per-GPU ~2.2배.** 150채널@5fps가 ~15장→~7장으로 절반. 의미 있지만 초기 ×4.4(불공정)는 과장이었음 — **검출 설정을 안 맞추면 비교가 통째로 틀어진다는 교훈.**
- **여전히 속도 측면만**이다. 반드시 함께 볼 것:
  - **검출 품질**: 검출 "수"는 맞췄지만 YOLO26은 COCO 일반학습 → 같은 수라도 **어떤 사람을 잡았나**(소형·원거리·가림)는 YOLOX-X-MOT20과 다를 수 있음.
  - **ID 일관성**: ByteTrack/BoT-SORT(기본)는 ReID 미사용 → 가림·교차 시 **ID 스위치 증가**. 잔류인원·체류시간 기능에 직접 영향.
- **권고**: ① 공정 영상 4개로 육안 품질 확인 → ② 수용 가능하면 **YOLO26m+ByteTrack 유력 후보**(~7장), 부족하면 **YOLO26 군중 파인튜닝** 또는 **BoT-SORT+ReID** → ③ 최종 선택 전 **HOTA/IDF1 정량 평가**로 정확도 비용 확정.
