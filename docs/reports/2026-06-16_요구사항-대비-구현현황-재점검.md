## 1. 신규 구현: 방향성 정렬도 (요구3) — 🟢 (단일 구역 MVP)

| 항목 | 상태 | 근거 |
|------|:----:|------|
| 기준(권장 피난) 방향 벡터 입력 | 🟢 | 운영자가 영상/맵에 **수동 화살표(꼬리→머리)** 작도 → `align_vec`. 단일 구역 1개 |
| 객체별 정렬도(코사인) | 🟢 | `speed.py` `align = dir_obj·ref_dir`. 객체·기준 같은 좌표계(H 있으면 월드) |
| 구역 평균 정렬도 | 🟢 | `avg_align`(이동 객체 평균, 정지 제외) |
| 사잇각 | 🟡 | 코사인으로 산출(각도는 평균만 환산 가능, 표시는 색 중심) |
| 표출 | 🟢 | 대시보드 "정렬도" 카드 + 2D 맵(정렬색 화살표 + 긴 기준 벡터) |
| opt-in | 🟢 | 화살표 그렸을 때만 동작(`has_align`) |

- 상세: [webui-dev/13-alignment.md](../webui-dev/13-alignment.md)

  임계(녹0.4/적−0.2)는 MVP 임의값. 정렬도는 **방향만**(속도 무시).

- **1 추적**: 발끝 대표점·ID·궤적 🟢. 멀티캠 병합 ⚪(보류).
- **2 평면도 좌표**: 픽셀→로컬 미터평면 🟢 / 실제 건물 도면 정합·왜곡보정 🔴.
- **3 속도·방향·정렬도**: 개별/구역 속도·방향 🟢 / **정렬도 🟢(단일 구역)** / 다구역 평균정렬도 🔴.
- **4 점유·밀도**: 단일 구역 인원·밀도 🟢 / **다구역·병목 동시** 🔴.
- **5 시간 이벤트**: 라인 교차 감지 🟢 / **피난 개시 시점·통과 타임스탬프·비상구 고유 통과(중복제거)** 🔴.

## 4. 다음 우선순위 (변동)

정렬도가 들어오면서 **피난 개시 시점(요구5)의 선행 입력이 확보**됐다. 권장 순서:
1. **피난 개시 시점**(요구5) — 이제 (평균속도 + 평균정렬도)가 있으니 임계·지속시간만 정하면 착수 가능.
2. **비상구 고유 통과수 + 타임스탬프**(요구5) — `LineCounter` 재설계(ID 최초통과 dedup + 시각 기록).
3. **다구역/다비상구·도면 정합**(요구2·4) — 확장성·다카메라 토대.
