## 1. 개요

이번 주는 **8월 최대 개발 주간**(97커밋)이다. CJ제일제당 현장 실증을 앞두고, 지표 산출의 단위를 "층 하나"에서 "건물 전체 훈련"으로 끌어올리고, 검출·ReID 엔진을 현장 조건에 맞춰 갈아끼울 수 있는 구조를 만들었으며, 현장 도면을 직접 다루는 편집기(:8910)를 실사용 가능한 수준으로 안정화했다. 축은 여섯이다.

- **건물 훈련(drill)** — 전 층이 하나의 경보 세션을 공유하고 4대 지표를 건물 단위로 롤업(ADR 06, 계약 v1.11). UI 표기는 "건물 훈련", 내부 코드·API는 `drill` 유지
- **검출기 투트랙** — YOLOX ↔ RF-DETR 를 갈아끼우는 구조 + RF-DETR TRT 원커맨드 셋업
- **추론 프로파일 교체구조** — 검출기·ReID·트래커 조합을 `model_zoo.py` 한 곳에서 전환(ADR 07). 신규 스택 YOLO26-L v6.3 + CLIP-ReID 도입·실측
- **도면 편집기(:8910) 안정화** — occupant 모드(출발점 지정)·도면 단위 자동 인식·미터 격자/스케일바·저장=운영 일원화 등 다수 결함 수정
- **CBS·SEI 정밀화** — CBS 부채꼴 영역·그룹 집계, SEI 문별 유효폭·통과 기준(계약 v1.12)
- **운영 편의·재현** — 카메라 일괄 등록, 전 카메라 커버영역 2D맵 표시, seed 버전 보관·원클릭 초기화, 사용 가이드 문서 파이프라인(v0.0.1→v0.0.5)

## 2. 건물 훈련 — 전 층 공유 세션·4대지표 롤업 (ADR 06, 계약 v1.11)

지금까지 경보 세션은 층 하나 단위였다. 실제 피난 훈련은 건물 전체가 동시에 움직이므로, 전 층이 **하나의 훈련 세션**을 공유하고 지표를 건물 단위로 합산하는 구조로 확장했다.

- **백엔드(Phase 1)**: 건물 전체 경보 세션 — 시작 게이트 + 공유 `t_alarm`(경보 시각) + 층별 결과 롤업(`bd9f009`). 참여 층 = 카메라가 매핑된 층, 원점(대피 시작점)은 매 훈련마다 새로 지정
- **프론트(Phase 1)**: 전 층 원점 게이트 + 건물 롤업 리포트(`1ba314f`) — 모든 참여 층에 원점이 지정돼야 훈련 시작
- **롤업·전 층 리플레이(Phase 2·3)**: 건물 드릴 롤업 스키마·export + 전 층 리플레이 재계산(`00c0d82`) — 건물 단위 4대 지표를 다시 계산·내보내기
- **IDR 설계 결정**: IDR은 구역별로 유지(요구사항 부합), 원점은 매 드릴 새로 지정(`0f22a5b`·`c5c431e`)
- **UI 표기 정리**: 화면 표기를 "드릴" → **"건물 훈련"**으로(`79fe893`). 내부 코드·API는 `drill` 유지(하위호환)
- **리플레이 연동**: ④ 리플레이 탭을 훈련 중심 UI로 — 다층 기본 = 건물 훈련, 층 전환 시 재생 위치·상태 유지(`736aaf7`·`14a476d`), 롤업 리포트 모달 닫기 결함 수정(`e86edac`)
- **문서**: ADR 06 · 계약 v1.11 · CLAUDE 반영(`8e2be9e`)

## 3. 검출기 투트랙 (YOLOX ↔ RF-DETR)

현장 조건에 따라 검출기를 바꿀 수 있도록, 기존 YOLOX 외에 RF-DETR를 드롭인으로 붙였다.

- **투트랙 구조**: `BoostTrackGPUInference(detector=...)` · CLI `--detector` 로 YOLOX ↔ RF-DETR 선택(`7ee33c1`). RF-DETR는 `src/rfdetr_trt.py`(라이브러리 불필요) + `tools/setup_rfdetr.sh` 원커맨드 셋업
- **TRT 변환·사용법 리포트**: RF-DETR base TRT fp16 변환·사용 절차를 재사용 가능하게 문서화(`69fae4d`)
- **자동 해상도 감지**: 엔진 입력 해상도 자동 감지 — Base(560)/Large(704) 등 변형을 무설정 드롭인(`f03d9c7`)
- **문서 전방위 반영**: README·이관가이드·`fetch_assets`·스킬·CLAUDE + HF ONNX 등록(`a66b489`)

## 4. 추론 프로파일 교체구조 (ADR 07) — YOLO26-L·CLIP-ReID 도입

검출기 하나만이 아니라 **검출기·ReID·트래커 조합 전체**를 프로파일 id 하나로 갈아끼우는 구조를 세웠다.

- **교체 지점 단일화**: 레포 루트 `model_zoo.py` 한 곳에서 프로파일 전환 — `yolox_fastreid`(기본, 기존 동작) ↔ `yolo26_clipreid`(YOLO26-L v6.3 + CLIP-ReID). 세 호출 지점(단일영상·ffmpeg 백엔드·DS 컨테이너)이 프로파일 id 하나만 받는다(`debd69c`)
- **:8900 UI 전환**: [① 설정 → 추론 모델] 패널에서 프로파일 선택(세션 중 전환 불가). 추론 모델 선택을 [지표 설명]처럼 별도 패널로 분리(`2a2a4a1`·`6ca590b`), RTSP 미리보기에 현재 추론 모델 표기(`3a67f17`)
- **실측**: 신규 스택(YOLO26-L + CLIP-ReID) 도입 실측 리포트 작성(`2026-08-20_신규-추론스택-YOLO26-CLIPReID-도입-실측.md`)
- 설계는 ADR 07, 엔진 빌드 `tools/build_profile_engines.sh`, ONNX는 `tools/fetch_assets.sh --onnx`

## 5. 도면 편집기(:8910) 대규모 안정화

CAD → 2D맵 편집기를 현장에서 실제로 쓸 수 있도록, 유저플로우 점검에서 나온 다수 결함을 수정했다.

- **occupant 모드(출발점 지정)**: 재실자 출발점을 찍는 모드 추가 + 버려진 출발점 사유 표시(`f808e63`·`3ad20f7`)
- **도면 단위 자동 인식**: `$INSUNITS`(도면 단위) 자동 인식 + 축척 승계 버그, 단위 미지정 도면이 안 열리던 문제 수정(`454fda0`·`067a2dd`)
- **미터 격자·스케일바 오버레이**(표시 전용) + 축척 출처 표시, 2점 축척이 CAD값을 덮어쓸 때 확인(`6bdd534`·`fe9614e`)
- **저장=운영 반영 일원화** + 우측 패널 정리(`da00b6a`) — 저장하면 곧 운영에 반영되도록 경로 통일
- **CAD 적용 잔존 수정**: CAD 적용 후 옛 경로·구역이 그대로 보이거나 수동 피난경로가 남던 문제, 교체할 층을 편집기에서 직접 선택(`cc25aa4`·`68055bc`·`5e8271d`), 편집 요소 개별 삭제(`cc3daa7`)
- **편집기 접근성**: CAD 편집기 팝업이 차단되면 열 수 있는 대체 링크 제공(`e1d41ac`)

## 6. CBS·SEI 정밀화 (계약 v1.12) · 출입구 판정

지표 정의를 현장 도면 조건에 맞게 정밀화했다.

- **CBS 부채꼴·그룹**: 병목을 문 위치에서 퍼지는 부채꼴 영역으로 잡고, 그룹 단위로 혼잡을 집계(`5529bd6`·`32ac402`). 병목 부채꼴 도구·그룹 입력 UI
- **SEI 문별 유효폭·통과 기준**: 출입구별 유효폭(W)·통과 기준을 문마다 인라인 입력(`5529bd6`·`32ac402`)
- **출입구 통과 판정**: 문이 화각 가장자리일 때를 위해 카메라 화면 '통과선'·'영역' 게이트 추가(`b586086`·`293a6f5`). 저장 경로에서도 출구 `C_j` 재파생(`fb22b25`)
- **리플레이 보정**: 녹화에 bbox 기록 — 화면 영역 출입구 리플레이 누락 수정(`7f75f16`)
- 계약 v1.12 · 요구사항 · 가이드 · 매뉴얼 v0.0.5 반영(`a9d68b9`)
