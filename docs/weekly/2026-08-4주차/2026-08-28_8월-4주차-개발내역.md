## 1. 개요

이번 주는 **현장 실증(CJ제일제당) 직전 준비 주간**이다. RTSP 카메라 없이도 리허설·시연을 돌릴 수 있는 "훈련영상 동기 송출 → 리허설 패키지" 라인을 완성하고, 지표 신뢰도의 핵심인 IDR 거리 계산의 오류를 잡아 요구사항을 개정했다. 축은 다섯이다.

- **훈련영상 동기 송출(ADR 08)** — 저장된 훈련 영상을 다채널 동기 재생, RTSP 없는 리허설·시연. 대기 송출(정지화면 standby) 포함
- **리허설 패키지 구조(ADR 09)** — `media/vsource/<site>/<set>/rehearsal.json`을 영상·시나리오·카메라·매핑의 정본으로. 사이트 층 빙의, 파일 모드 잠금 동기 추론, CJ 14대 매핑 완료본
- **4대지표 거리 계산 검증·정정** — IDR 거리가 맨해튼이던 버그를 8방향 다익스트라로, D를 '사람 위치' 기준으로(요구사항 §4.1 개정), 구역 전체 거리 계산 4.8s→0.34s
- **vsource 정비** — 훈련 시작 앞 유실 보정·준비 단계 병렬화·리허설 전용 매핑·배지
- **운영뷰·UI** — [표시] 레이어 토글, ①·②에 Ctrl+Z, legacy mock 시나리오 제거

## 2. 훈련영상 동기 송출 (ADR 08)

현장 NVR/RTSP가 없는 환경에서도 리허설·시연을 돌리기 위해, 저장된 훈련 영상을 여러 채널에 **동기 재생**하는 경로를 만들었다.

- **설계·확정**: ADR 08 설계 → 인터뷰 반영해 재작성·확정(`9d44914`·`bff7dc0`)
- **동기 송출 구현**: 훈련영상 동기 송출 — 리허설·시연용(`909fe1d`). 시나리오 검증에 카메라 매핑 상태 포함(`d263891`)
- **대기 송출(standby)**: 매핑은 되어 있고 영상은 정지화면으로 멈춰 있는 대기 상태(`176c8be`) — 채널 행 클릭 시 그 카메라 매핑 화면으로(`9c0a1cd`), 재생 중 채널 클릭 시 자동으로 대기 전환(`fc2f30c`), standby도 pm2 복구 목록 승계(`2a6887d`)
- **운영 경로 정합**: 훈련 시작을 ②에서 빼고 ③ [경보 시작]에 붙임(`b7d983f`), 리허설 밖 카메라 파킹 + 참여 층 판정에 `enabled` 반영(`602a53f`)
- ADR 08 상태를 구현 완료로 갱신(`89f11fb`)

## 3. 리허설 패키지 구조 (ADR 09)

동기 송출을 "폴더 하나가 진실의 원천"인 패키지로 정착시켰다. 영상·시나리오·카메라·매핑을 한 곳에 묶어, 사이트 층에 빙의시켜 재생한다.

- **패키지 구조·파일 소스 모드**: `media/vsource/<site>/<set>/rehearsal.json` = 영상·시나리오·카메라·매핑 정본. RTSP 없는 **파일 모드 잠금 동기 추론**(`2a630f2`). 준비 CLI `tools/rehearsal_prep.py`, 오프라인 진단 `tools/rehearsal_viz.py`
- **영상 정본 HF 이관**: 영상을 `backseollgi/MCMOT/media/vsource/**`(레포 경로 미러)로, `fetch_assets.sh --rehearsal` 경로·토큰 폴백(`b7d479a`)
- **리허설=건물 세션**: 리허설은 항상 건물 세션으로 — 드릴 명시 레코드(층 범위·라벨), ④ 기본 모드 건물 훈련(`a09811b`). 리허설 중 사이트 RTSP 파킹(GPU 해제)·다층 카메라별 층·커버리지 현재 층만(`040f68a`)
- **전체 연속 시나리오**: 01~14 를 이어 붙이고 없는 카메라 구간은 검정(간격 4s), 14대 프레임 동일(`80085f2`). 검정 구간 매핑 엣지·경고 문구 정리(`e1bceef`·`530fe08`)
- **CJ 14대 매핑 완료본**: CJ 리허설 14대 매핑 완료 + seed v9(10F 출입구 2·병목 2·경로 8)(`1a05d8f`). 촬영기록·카메라 위치 도면을 패키지 `docs/`로 구조화(`c0a42b9`)
- **파일 모드 자동 종료**: 파일 모드 영상 끝 → 리허설 세션 자동 종료·저장(`VSOURCE_AUTO_END_SESSION`)(`aca5928`), 자동 종료된 건물 훈련도 ③에 롤업 결과 모달 표시·seed v10(`8366abe`)

## 4. 4대지표 거리 계산 검증·정정 (요구사항 §4.1 개정)

지표 신뢰도의 핵심인 IDR(피난 반응 확산)의 거리 계산에서 오류를 발견해 정정하고, 요구사항을 개정했다.

- **IDR 거리 맨해튼 버그 → 8방향 다익스트라**: 거리가 맨해튼(격자)이던 것을 8방향 다익스트라로(`e2fb88c`) — 오차 +39% → ±6.5%. 요구사항도 8방향으로 개정 + 구역 나눔 권고(`2e081ba`)
- **D를 '사람 위치' 기준으로**: IDR의 D(확산 거리)를 사람 위치 기준으로 재정의(요구사항 §4.1 개정)(`05f4fd4`) + 앞선 측정 정정. 검토 근거(`f821f76`·`33db4ec`)
- **성능**: 구역을 도면 전체에 깔 때의 거리 계산 4.8s → 0.34s(`e2d1423`)
- **검증 테스트**: 속도 계산이 샘플링 fps에 독립인지, analyze_fps 게이트 검증(`3e62aa2`·`ffed9b7`)
- **리포트**: 거리 계산 검증 결과를 리포트로 정리(`2026-08-27_4대지표-거리계산-검증.md`)
- **AI-Hub 도면 파이프라인**: AI지원센터 층별 평면도 추출 파이프라인 문서·스크립트(`4db1bfc`·`fa38580`) — 실증 시나리오 문서 포함

## 5. vsource 정비 (동기 송출 안정화)

동기 송출을 실제로 돌리며 나온 타이밍·성능 결함을 잡았다.

- **훈련 시작 앞 유실 보정**: 훈련 시작 앞 27초 유실을 정지화면 앞머리로 덮음(`38e3d24`), 앞머리 길이를 정수 초로 — fps 혼재 시 채널마다 어긋나던 것(`3fd218e`)
- **준비 단계 병렬화**: 채널 확장 대비 12ch start 41.7s → 12.1s(`570ad2c`), 대기 송출이 20초 걸리고 진행이 안 보이던 문제(`3c6b465`)
- **리허설 전용 매핑**: production 무변경으로 리허설 전용 매핑(`6dd3c57`), 파킹 폐기·훈련 범위 제한·⑤ 전용 탭·단계 표시(`ade22d4`), 리허설 시작을 전용 버튼으로 분리(`13ce82d`)
- **UI 정합**: ② 배너 축소 + 리허설/평상 채널 구분 배지(`62a9537`)
