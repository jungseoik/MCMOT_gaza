# docs/weekly — 주간 미팅/진척 보고서

주간 미팅(삼성화재 등) 자료를 **주차별 폴더**로 모은다.

- 폴더 컨벤션: `YYYY-MM-N주차/` (예: `2026-06-3주차`)
- 폴더 안에 보고서 `YYYY-MM-DD_제목.md` + 이미지 `img/`
- 각 주차 폴더에 인덱스 `README.md`를 둔다.

|------|------|-----------|
