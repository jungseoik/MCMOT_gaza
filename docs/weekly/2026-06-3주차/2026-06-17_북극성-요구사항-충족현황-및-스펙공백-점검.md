## 1. 목적

이 점검의 목적은 다음과 같다. 이번 주 코드 상태를 기준으로 북극성 5대 요구사항이
**어디까지 충족됐는지**, 미충족·애매한 항목은 **무엇이 부족한지**를 정리. 특히
"요구사항이 지금 상황에서 무엇을 요구하는지 **정보·스펙이 부족한 부분**"을 별도로 명시.

범례: ✅ 충족 · ◐ 부분 충족 · ❌ 미충족.

## 2. 카테고리별 충족 현황

북극성 5대 카테고리의 세부 요구 항목별 충족 현황은 다음과 같다.

| 카테고리 · 요구 항목 | 충족도 | 현재 상태 | 부족한 것 / 필요 정보 |
|---|:---:|---|---|
| **1. 대표점 픽셀 좌표** | ✅ | 발끝점(박스 하단 중심) 산출 | — |
| **1. 시계열 ID 궤적** | ✅ | BoostTrack++로 id 유지, 시간순 좌표 저장 | — |
| **1. Multi-Camera ID 병합** | ❌ | 단일 카메라 동작(요구사항도 최종 단계) | 카메라 배치·FOV 중첩 영역·시간 동기·대상 현장 토폴로지 미제공 |
| **2. 평면도 좌표 변환** | ◐ | 픽셀→지면 미터 좌표(ROI 4점·Depth 자동) | **실제 건물 도면(평면도)** 과 카메라↔도면 정합 기준점(GCP), 설치 높이·각도 파라미터 미제공 |
| **3. 개별 이동속도·방향 벡터** | ✅ | km/h(보정 시)·방향 단위벡터 산출 | — |
| **3. 구역 평균 이동속도** | ✅ | 구역 내 속도 절대값 평균 | — |
| **3. 방향성 정렬도** | ◐ | 코사인 유사도·구역 평균 산출 | 사잇각(°) 미산출, **권장 피난 경로 방향**이 운영자 수동 2점(시스템 자동 산출 아님), 정렬 임계값 도메인 미정 |
| **4. 구역별 재실자 수** | ◐ | ROI 다각형 포함 판정으로 카운팅 | ROI **1개**만 — 문·계단·복도 등 **다구역 동시 정의** 미지원, 현장별 구역 경계 미제공 |
| **4. 병목영역 밀도** | ✅ | 인원 ÷ 실제 바닥면적(명/m²) | 병목 후보영역 **정의 기준**, 혼잡 판정 밀도 임계 도메인값 미정 |
| **5. 피난 개시 시점** | ❌ | 미구현 | 속도·정렬도·충족비율 **임계치**와 **지속시간** 기준이 도메인 미정 |
| **5. 가상선 통과 이벤트·완료 시점** | ◐ | 통과 순간 감지·IN/OUT 집계 | 객체별 **통과 타임스탬프(완료 시점) 기록** 미구현 |
| **5. 비상구별 고유 통과 수** | ❌ | 통과마다 +1(중복 집계) | 고유 ID **최초 통과만** 집계하는 dedup 미구현, 비상구↔가상선 매핑 정의 필요 |

## 3. 정보 부족·애매 요구사항 (스펙 공백)

미충족·애매 항목의 상당수는 구현 난이도보다 **결정·입력 정보의 부재**가 원인이다. 채워져야
진행 가능한 스펙 공백은 다음과 같다.

| # | 미결 스펙 | 어느 요구사항이 막히나 | 필요한 결정 / 입력 |
|---|---|---|---|
| 1 | **대상 건물 평면도(도면)** 부재 | 2(평면도 좌표), 4(구역 정의) | 실제 도면(CAD/이미지) + 도면-영상 정합 기준점 |
| 2 | **카메라 설치 토폴로지** 부재 | 1(Multi-Cam), 2(캘리브) | 카메라 위치·높이·각도, FOV 중첩 영역, 시간 동기 방식 |
| 3 | **분석 구역·비상구·병목영역 정의** 부재 | 4(재실/밀도), 5(통과) | 현장별 구역 경계 좌표, 비상구별 가상 통과선 매핑 |
| 4 | **도메인 임계값** 미정 | 3(정렬), 4(혼잡), 5(피난 개시) | 혼잡 밀도 기준, 정렬도 임계, 피난 개시 속도·정렬·지속시간 기준 |
| 5 | **권장 피난 경로 산출 방식** 미정 | 3(정렬도), 5(피난 개시) | 경로를 시스템이 자동 산출할지(알고리즘·입력) vs 운영자 수동 지정할지 |

> 현재 임계값(혼잡 0.4·1.0 명/m², 정렬 0.4·−0.2)은 **MVP 임의값**이며, 위 4번이 확정되면 교체.

## 4. 종합 현황

세부 요구 항목 12개의 충족 현황을 집계한 결과는 다음과 같다.

| 충족도 | 개수 | 항목 |
|:---:|:---:|---|
| ✅ 충족 | 5 | 대표점·궤적·개별속도/방향·구역평균속도·밀도 |
| ◐ 부분 | 4 | 평면도 좌표·정렬도·구역 재실자수·가상선 통과 |
| ❌ 미충족 | 3 | Multi-Cam 병합·피난 개시 시점·비상구 고유 통과 |

- **충족 핵심**: 단일 카메라 기준 추적·속도·방향·밀도의 1차 산출은 완료.
- **부분 충족의 공통 병목**: 미터 좌표는 되나 **실제 도면 정합**·**다구역**·**자동 경로**가 미흡.
- **미충족 3건**: 시간 이벤트(피난 개시·고유 통과)와 Multi-Camera(최종 단계) 영역.
