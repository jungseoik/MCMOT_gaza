## 당월(8월) 주요 진척사항

□ CJ제일제당 현장 PoC 사전 테스트 수행 및 시스템 연동 결과 확인
  - 실증 현장(CJ제일제당센터 10층) 방문, PoC 사전 테스트 수행 — 카메라 6대를 도면상 14개
    지점으로 옮겨가며 피난 시나리오 15종 촬영, 카메라 간 녹화 시작 시각 동기화 보정.
  - 현장 테스트 결과를 시스템에 연동 — 카메라 14대의 영상 속 위치를 도면 좌표로 변환(매핑),
    10층 출입구 2·병목 2·권장 피난경로 8 구성 후 훈련 전 과정과 4대 지표 산출 결과를 확인.
  - CCTV 녹화·전송 장비(NVR) 연결 이전 단계에서 카메라 위치·화각·매핑 문제를 사전 도출,
    실증 당일 운영 절차 확정.

□ 건물 전체 훈련 기능 — 전 층 동시 세션·4대 지표 건물 단위 산출
  - 층 하나 단위였던 경보 세션을 전 층이 하나의 훈련(경보 시각 공유)으로 묶이도록 확장.
  - 참여 층 전부에 대피 시작 기준점 지정 시 훈련 시작, 종료 시 층별 지표 + 건물 전체
    4대 지표 합산 리포트 제공(전 층을 한꺼번에 다시 재생·재계산 포함).

□ 훈련영상 동기 송출·리허설 패키지 — 현장 CCTV 없이 훈련 전 과정 재현
  - 저장된 훈련 영상 여러 대를 시간 맞춰 동시 재생, 실제 훈련과 동일한 절차(운영 화면 →
    경보 시작 → 지표 산출) 수행.
  - 영상·시나리오·카메라·매핑을 폴더 하나로 묶어 다른 서버에서도 동일 리허설 재현.

□ 4대 지표 계산 정확도 검증 및 정정
  - IDR(피난 반응 확산) 거리 계산이 상하좌우 격자로만 이동해 실제보다 멀게 나오던 오류를
    대각선 포함 최단경로로 정정(오차 +39% → ±6.5%), 요구사항 개정 및 이전 측정값 정정 반영.
  - CBS(병목 혼잡)는 문에서 퍼지는 부채꼴로 병목을 지정·그룹 집계, SEI(비상구 활용)는
    출입구별 유효 폭·통과 기준을 문마다 입력하도록 정밀화.
□ 추론 모델(AI 엔진) 교체 구조 및 운영 안정화
  - 사람을 찾아내는 검출 모델 두 종류(YOLOX ↔ RF-DETR)와 검출·재식별(같은 사람 판별)·추적
    조합을 설정 한 곳에서 교체하는 구조 구축 — 현장 정확도 미흡 시 즉시 대안 전환.
  - CAD 도면 편집기를 현장 도면 실사용 수준으로 안정화, 카메라 일괄 등록·설정 초기화 추가.
  - 실제 화면 기반 사용 가이드 v0.0.6(53쪽, PDF·Word) 배포.

## 익월(9월) 주요 예정사항

□ CJ제일제당 현장 실증 수행

  - 사전 테스트로 검증한 절차를 실제 훈련에 적용해 4대 지표 산출.
  - 현장 CCTV(NVR) 연결 방식·인코딩 조건을 당일 진단으로 확정하고 수집.

□ 서울 AI Hub 현장 실증 수행

  - 약 10명 규모로 4대 지표 검증 시나리오(지표별 4종, 총 16종) 촬영·분석 — 지표 판정 조건을
    의도적으로 만족/불만족시켜 산출값이 설계대로 나오는지 검증.
  - 층별 평면도 추출·구역·경로·비상구 구성은 8월 완료, 실증 결과로 판정 기준값 기본안 확정.

□ 종합평가(KPI) 및 회차 비교 기능

  - 총 대피 시간·구간별 통과 시간·최대 혼잡도·병목 구간 등을 산출하고 회차별 비교하는
    대시보드 개발(훈련 기록 저장·재계산 토대는 구현 완료).
