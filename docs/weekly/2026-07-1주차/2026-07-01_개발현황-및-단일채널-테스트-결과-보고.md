## 1. 요약

이번 주 핵심은 **단일 채널 기준으로 개발한 기능의 정량 검증**이다. 핵심 피난지표 추출 기능은
대부분 구현 완료 상태이며, 이번 주는 공개 데이터셋(AI-Hub)·실내 촬영 영상으로 **추적·검출
정확도**와 **거리 측정 정확도**를 수치로 확인. 다채널 확장·피난 이벤트 산출은 남은 과제.

- **추적**: YOLO26-L + BoostTrack++ 조합 최고 — IDF1 **0.834** (AI-Hub 북촌)
- **검출**: 정밀도 **0.92~0.95**, 재현율은 밀집·원거리에서 하락
- **거리 측정(Depth)**: 6개 기준점 평균오차(MAE) **0.35m** (근거리 0.06~0.14m)

## 3. 단일 채널 테스트 결과

### 3.1 추적·검출 정확도 — AI-Hub 군중 시퀀스 3종

AI-Hub 군중 시퀀스(북촌 203·EXCO133·EXCO095)로 YOLO26 검출기(L/N) + 트래커(BoostTrack++·
BoT-SORT-ReID)를 평가. AI-Hub 정답은 **머리 박스**, 검출은 **전신**이라 IoU 기반 지표가 0에
가까워, 라벨에 충실한 **포인트 매칭**(정답 머리점이 예측 박스 안에 포함되면 검출)으로 산출.

**추적 (북촌 203 — 트랙 ID 정답 존재)**

| 검출기 | 트래커 | IDF1 | MOTA | IDS |
|--------|--------|:----:|:----:|:---:|
| YOLO26-L | **BoostTrack++** | **0.834** | **0.815** | 43 |
| YOLO26-L | BoT-SORT-ReID | 0.791 | 0.812 | 49 |
| YOLO26-N | BoostTrack++ | 0.752 | 0.673 | 63 |

→ **YOLO26-L + BoostTrack++ 최고**(IDF1 0.834). BoostTrack++가 BoT-SORT를 상회, 검출기 크기(L>N) 영향이 가장 큼.

**검출 (person, conf ≥ 0.4 · YOLO26-L)**

| 시퀀스 | 정밀도 | 재현율 | F1 | Count MAE |
|--------|:----:|:----:|:----:|:----:|
| 북촌 203 (중밀도·실내) | 0.929 | 0.806 | 0.863 | 1.63 |
| EXCO133 (중밀집) | 0.916 | 0.622 | 0.741 | 4.19 |
| EXCO095 (고밀집·원거리) | 0.916 | 0.232 | 0.371 | 17.35 |

→ **정밀도는 전 구간 높음**(오탐 적음), **재현율은 밀집·원거리에서 하락**(작거나 가려진 인물 누락). 실내 중밀도(북촌)에서 인원 오차 MAE 1.63명.

### 3.2 방향성 정렬도 기능 구현

권장 피난 방향과 개별 이동 방향의 **코사인 유사도**로 "지시 방향대로 이동하는가"를 지표화(MVP).
대시보드 "Alignment 정렬도" 카드 + 2D 맵 정렬색(녹/황/적)·기준 벡터로 표출.

### 3.3 Depth 기반 거리 측정 (협착 근접감지 프로토타입)

UniDepth V2(상대 거리) + 정자세 규칙 기반 캘리브레이션으로 **실제 거리**를 추정. 실내에서
기준점 6개(2.5~5.0m)·테스트 영상 10개로 정량 평가.

| 지표 | 값 |
|------|-----|
| Distance MAE | **0.350 m** |
| Distance RMSE | 0.425 m |
| Max Error | 0.90 m (D=5.0m) |

→ **근거리(2.5~3.0m) MAE 0.06~0.14m로 매우 정확**, 원거리(5.0m)에서 MAE 0.65m로 과소추정 경향.
정자세 추정 로직·bbox 순간 튐(jitter) 보정이 고도화 과제.

### 3.4 도면 기반 검증 자산 (17F 평면도·지도 정합·합성 CCTV)

CJ제일제당 **17층 평면도(CAD)·피난경로(egress route)** 확보. CCTV 영상을 실제 도면에 **N점
호모그래피로 정합**(2D map registration)해 발끝을 도면 좌표(미터)로 변환·표시. 실제 CCTV가
아직 없어, 도면 기반 **합성 CCTV 영상 + 정답(GT)** 생성 엔진(`cad/synth`)으로 5대 지표를 정량
검증할 대체 데이터도 구축.

## 4. 남은 업무 / 해야 할 것

- **다채널 스케일업 (1 → 15 → 150ch)**: 현재 단일 채널 단계. 동시 처리 아키텍처·GPU 분산 필요 (WBS 4.7).
- **피난 이벤트 산출**: 피난 개시 시점, 비상구 **고유 통과(중복 제외)** — 미구현 (WBS 4.3.7/4.3.8).
- **Depth 거리 측정 고도화**: 정자세 로직·bbox jitter·원거리 과소추정 보정.
- **밀집·원거리 검출 재현율 개선**: 고밀집 장면(EXCO095) 소형·가림 인물 누락 완화.
- **대피 경로 데이터 모델링·탐색**: 17층 피난경로 도면 확보(입력). Node-Edge 그래프 모델링·탐색(WBS 4.5.x) 미착수.
- **대시보드 종합평가·KPI**: 회차별 KPI(총 대피시간·통과시간·혼잡도·병목) 산출·비교.
- **현장 실증 사전 준비(CJ제일제당)**: 카메라 구성·분석 구역·캘리브레이션 확정(도면은 확보).
