카메라 각도 약 20~25도
측정인 : 이정원, 본인 키 (1.7m)

우선 카메라 캘리브레이션을 시키기 위하여 카메라 정면 뷰를 4개의 사분면으로 나누고,
각 사분면마다 한번씩 정자세로 서있다고 가정한 후 캘리브 완료 시 각 지점에 서 있는 방법

### 거리 추정 평가 지표

#### 1. 지표 정의

- **Distance MAE (평균 절대 오차):** 예측 거리와 실제 거리(GT) 차이의 절댓값 평균. 값이 작을수록 평균적으로 정확함
- **Distance RMSE (평균 제곱근 오차):** 오차를 제곱해 평균 낸 뒤 제곱근
큰 오차에 더 민감하므로 MAE보다 크면 이상치(튀는 오차)가 있다는 신호
- **Max Error (최대 오차):** 전체 예측 중 가장 큰 절대 오차
최악의 경우(worst-case) 성능 지표
- **Zone-wise Error (구역별 오차):** 기준점(A~F)별로 따로 계산한 오차
어떤 위치/거리에서 모델이 약한지 진단

#### 4. 해석 요약

- **근거리(A·B·C, 2.5~3.0m)** 는 MAE 0.06~0.14m로 매우 정확함
- **비교적 원거리(D·E·F, 3.5~5.0m)** 로 갈수록 오차가 커지며, 특히 **D(5.0m)** 에서 MAE 0.65m로 가장 큼
