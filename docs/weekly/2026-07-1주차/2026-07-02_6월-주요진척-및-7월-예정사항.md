## 당월(6월) 주요 진척사항

6월에는 **실시간 분석 웹 UI(사용자 화면)를 통합 구축**하고 그 위에서 **핵심 피난 분석 기능을
완성·검증**했으며, 실제 CCTV 환경에 가까운 **실시간 스트리밍·지도 정합 테스트**와 하반기
CJ제일제당 현장 실증을 위한 **준비 자산·계획**까지 확보했습니다.

### 1. 실시간 분석 웹 UI(webui) 통합 플랫폼 구축
- 여러 분석 기능을 한 화면에서 쓰는 **통합 웹 UI**를 구축했습니다(초기 Streamlit 시제품 →
  FastAPI 기반으로 일원화). 영상 업로드 또는 실시간 스트림을 받아 분석하고, 우측 **실시간
  대시보드**와 **2D 지도(위에서 내려다본 평면)** 로 결과를 표시합니다.
- 분석 모드: 속도·밀도, 인·아웃 카운팅, 지도 정합, Depth 거리 보정, 기본 시각화(결과 영상 다운로드).

### 2. 핵심 분석 엔진(단일 채널) 완성 및 정확도 정량 검증
- 영상 속 사람을 찾아내고(검출), **같은 사람에게 계속 같은 번호를 붙여 추적**하는 기능,
  이동 속도·방향, 구역별 인원·밀도(혼잡도) 등 피난 분석의 핵심 지표를 갖췄습니다.
- 공개 군중 영상(AI-Hub)으로 정확도를 **수치로 검증**했습니다.
  - **추적 정확도 IDF1 0.834** — IDF1은 "영상 내내 한 사람에게 같은 번호를 얼마나 잘 유지하는가"를
    0~1로 나타내는 지표로, **1에 가까울수록 우수**합니다(0.83은 높은 수준).
  - **검출 정밀도 92~95%** — 모델이 "사람"이라고 지목한 것이 실제로 사람일 확률(오탐이 적음).
- 공항 대기열 등 실제와 유사한 **군중 영상 22편(C-LAB 샘플)** 에 대해서도 추적 결과를
  좌(ID 추적)·우(2D 지도)로 시각화해 **정성 검증**을 수행했습니다.
- 다만 사람이 매우 **밀집하거나 멀리 있는 장면에서는 놓치는 사람(미검출)이 늘어**, 이 부분은
  개선 과제로 확인했습니다.

### 3. 인·아웃(In/Out) 통과 카운팅 및 재실 추정
- 출입구에 **가상의 선**을 그으면 그 선을 넘는 사람을 **들어옴/나감**으로 세고, **현재 남아 있는
  인원(재실)** 을 실시간 추정합니다(재실 = 들어온 수 − 나간 수). 폐쇄공간 잔류 인원 파악에 활용.

### 4. 방향성 정렬도 기능 개발
- 사람들이 **지정한 대피 방향대로 움직이는지**를 하나의 숫자로 나타내는 지표를 개발했습니다.
- 각자의 이동 방향과 권장 대피 방향이 얼마나 같은지를 **코사인 값(두 방향이 같으면 +1, 직각이면 0,
  정반대면 −1)** 으로 계산합니다. **역류(반대로 가는 사람)** 를 색으로 즉시 구분할 수 있습니다.

### 5. Depth(깊이) 기반 거리 측정 시험(프로토타입)
- 카메라 한 대만으로 사람까지의 **실제 거리(미터)** 를 추정하는 기능을 시험했습니다
  (딥러닝 깊이 추정 + 사람 키를 기준으로 한 보정).
- 실내 실측에서 **평균 오차 0.35m**, 특히 **가까운 거리(2.5~3m)에서는 0.1m 수준**으로 정확했습니다.
  → 사람 간 **협착(끼임)·근접 위험 감지**에 활용 가능성을 확인. 먼 거리 정확도는 보완이 필요합니다.

### 6. RTSP 실시간 스트리밍 및 릴레이 서버 환경 테스트
- 실제 CCTV처럼 영상을 **RTSP(영상 실시간 전송 표준)** 로 내보내는 **릴레이(중계) 서버**를
  구축하고(mediamtx + pm2로 상시 송출), 웹 UI가 이 스트림을 실시간으로 받아 분석하는 **실환경에
  가까운 테스트**를 수행했습니다. → 저장된 파일 재생이 아닌 **실시간 처리 경로**를 검증.

### 7. 2D 지도 정합 및 실환경 이미지 정합 테스트
- CCTV 영상 속 사람 위치를 **실제 건물 평면도(지도) 위의 좌표로 변환**해 지도에 표시하는 기능을
  개발했습니다(**호모그래피**: 한 평면의 좌표를 다른 평면의 좌표로 대응시키는 변환).
- 위 RTSP로 송출한 **실제 영상**을 도면 지도에 정합해, 사람이 지도 위 올바른 위치에 표시되는지
  **실환경 테스트**를 진행했습니다.

### 8. 다채널 확장 타당성 및 검출기 성능 실측 분석
- 카메라 여러 대를 **동시에 처리(스케일업)** 할 수 있는지 미리 실측했습니다 — 검출기 YOLO26
  계열 비교, 입력 해상도별 처리량, **GPU 2장 병렬 처리량** 측정.
- 결과: **15대 수준은 현재 구조로 달성 가능**, **150대(최종 목표)는 추적 경량화 + GPU 증설이
  필요**하다는 확장 로드맵 근거를 확보했습니다.

### 9. CJ제일제당 실증 준비 자산 확보
- 실증 대상인 **17층 평면도(CAD)와 피난경로 도면**을 확보했습니다.
- 실제 현장 CCTV가 아직 없는 상황이라, **도면을 바탕으로 가상 CCTV 영상과 정답 데이터를 만들어**
  엔진을 미리 정량 검증할 수 있는 도구(합성 영상 생성기)를 개발했습니다.

### 10. 실증(PoC) 계획 수립 및 과제 관리 체계 정비
- **CJ제일제당 피난대피훈련 실증 계획**을 수립했습니다(수행: 삼성화재 C-Lab Outside,
  일정: 8월 말~9월 초 잠정).
- **북극성(핵심 요구사항) 대비 구현 현황·충족도**를 여러 차례 점검하고, 미구현 항목의 선결
  요건을 정리했습니다.
- 프로젝트 작업 목록(WBS)을 실제 개발 현황에 맞게 정비하고, **카메라 확장 목표(1대 → 15대 →
  150대 동시 처리)** 를 명문화했습니다.

## 익월(7월) 주요 예정사항

7월에는 **여러 대 카메라 동시 처리**와 **피난 이벤트 자동 산출**을 중심으로, 8월 말 현장 실증을
대비한 준비를 진행할 예정입니다.

### 1. 다채널(여러 대 카메라) 동시 처리 확장 착수
- 현재 카메라 1대 → **여러 대(우선 15대) 동시 분석**으로 확장(최종 목표 150대).
- 여러 영상 스트림을 동시에 처리하기 위한 구조(작업 분산·GPU 자원 분배)를 개발합니다.

### 2. 시간 기반 피난 이벤트 산출
- **피난 개시 시점**(사람들이 실제로 대피를 시작한 순간)을 자동으로 검출.
- **비상구별 고유 통과 인원** 집계 — 같은 사람이 왔다 갔다 해도 **최초 1회만** 세어(중복 제외)
  실제 대피 인원을 정확히 파악.

### 3. 거리 측정·검출 정확도 고도화
- Depth 거리 측정의 **먼 거리 오차 보정**, 사람이 밀집하거나 멀리 있을 때 **놓치는 인원 감소**.

### 4. 대시보드 종합평가(KPI) 기능
- 훈련 결과를 평가하는 핵심 지표(**총 대피 시간, 구간별 통과 시간, 최대 혼잡도, 병목 구간** 등)를
  산출하고 회차별로 비교하는 기능을 개발합니다.

### 5. CJ제일제당 현장 실증 사전 준비
- 현장 **카메라 구성·분석 구역 정의·캘리브레이션**(카메라 화면을 실제 도면 좌표에 맞추는 보정)을
  확정 — 8월 말~9월 초 실증에 대비합니다.
