## 1. 개요

8월 말 CJ제일제당 현장 실증을 앞두고, 이번 주는 **신규 기능보다 현장 자산·재현 정합**에 집중한 주다. 실 건물의 전 층 도면을 확보해 :8900에 편입하고, 디폴트 세팅(seed)을 현재 라이브 상태와 완전히 일치시켜 "클론 + fetch 만으로 현재 운영상태 재현"의 정합을 맞췄다.

- 실 건물 **지상1층 도면**을 :8900의 1F floor로 추가(CAD 척도만)
- **지상1~20층 전체 평면도** 최종본을 HF에 등록, `fetch_assets.sh --cad`로 연결
- default 사이트 **seed를 현재 라이브와 완전 동기화**(재현 정합)
- **재현성 감사** 결과 반영 — 시드 3개 층(+지상1층)·`.env SESSION_RECORD`

---

## 2. 실 건물 전층 도면 확보 (지상1~20층)

CJ제일제당 실 건물의 전 층 CAD 평면도를 확보·정리해 재현 자산에 편입했다.

- **지상1층 도면**을 :8900에 1F floor로 추가(`c977bcc`) — 이 시점은 CAD 척도(스케일)만 반영, 공간요소(구역·경로·출입구) 드로잉은 이후 매핑 단계에서 진행
- **지상1~20층 전체 평면도 최종본**을 HF(`backseollgi/MCMOT`)에 등록하고 `tools/fetch_assets.sh --cad` 다운로드 경로에 연결(`a59454b`) — 새 서버에서 clone + `fetch_assets --cad` 만으로 전층 도면 확보
- 도면은 대용량·현장 자산이므로 git 이 아닌 HF 레포에 둔다(코드/설정은 git, 대용량은 HF 원칙 유지)

---

## 3. 재현 정합 — seed 라이브 동기화·감사 갭

새 GPU 서버에서 "현재 운영상태 그대로 재현"이 실제로 성립하는지 감사하고, 어긋난 지점을 정정했다.

- default 사이트 **seed를 현재 라이브와 완전 동기화**(`cfd496c`) — `[Reset]`이 복원하는 디폴트 상태가 실제 운영 중인 매핑·요소와 일치하도록 정합. 재현 시 라이브와 seed가 갈라지던 문제 해소
- **재현성 감사 갭 반영**(`de4c0d8`) — 시드가 3개 층(+지상1층)을 담도록, `.env`의 `SESSION_RECORD`(세션 녹화 on/off) 문서화 등 재현 절차 문서의 구멍을 메움
