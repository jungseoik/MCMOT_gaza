## 1. 개요

CJ제일제당 사업장의 **실제 피난대피훈련**을 대상으로, 영상분석 엔진이 대피 과정에서 **추출 가능한
피난지표**를 실시간 산출 → **대시보드**로 확인 → 훈련 종료 후 **종합평가**하는 실증.
**실데이터(실제 훈련)** 기반 검증.

## 2. 실증 수행 부서 / 협력 체계

| 구분 | 주체 | 비고 |
|------|------|------|
| PoC 수행(주관) | **삼성화재** (투자운영파트 · 기업안전연구소) | C-Lab Outside 주관 |
| 실증 장소 제공 | **CJ제일제당** | 세부 사업장·대상 구역 확인 필요 |
| 기술 수행 | 피난 분석 엔진 개발팀 | 엔진·대시보드·캘리브레이션 |

## 3. 실증 대상 및 환경

- **대상**: 피난대피훈련 시 대피 인원의 이동·동선
- **입력**: 현장 CCTV(RTSP) — 카메라 수·해상도·설치 구도 확인 필요
- **분석 구역**: 비상구·계단·복도 협소부 등 **병목 후보영역**(현장 도면 기반 정의 필요)

## 4. 기술실증(PoC) 진행 계획 (상세)

### 4.1 사전 준비 (실증 전, ~8월)

- 현장 **CCTV 현황·평면도 확보**, 분석 구역(ROI)·비상구 **가상 통과선** 정의
- **카메라 ↔ 평면도 캘리브레이션**(호모그래피) — 픽셀 → 실제 미터 좌표 변환
- **다채널 구성**(훈련 카메라 수만큼) + RTSP 연동 검증
- 도메인 파라미터 협의·설정(혼잡 밀도 기준, 정렬도·피난 개시 임계, 지속시간)

### 4.2 훈련 중 실시간 5대 피난지표 추출

| # | 피난지표 | 산출 내용 |
|---|----------|-----------|
| 1 | 객체 추적 | 재실자 검출·고유 ID 추적·시계열 궤적 |
| 2 | 평면도 좌표 | 도면상 2D 위치(호모그래피 변환) |
| 3 | 이동 속도·방향 | 개별 속도(km/h)·방향 벡터, 구역 평균속도, **방향성 정렬도**(권장 대피방향 대비) |
| 4 | 구역 밀도 | 구역별 재실자 수, 병목영역 밀도·혼잡도(여유/보통/혼잡) |
| 5 | 시간 이벤트 | **피난 개시 시점**, 비상구 가상선 통과·완료 시점, **잔류인원**(폐쇄공간 재실) |

### 4.3 대시보드 표출

- 실시간 모니터링: 인원·평균속도·밀도/혼잡도·정렬도·잔류인원 + **2D 평면 맵**(점·이동 방향)

### 4.4 종합평가 (훈련 후)

- **회차별 KPI**: 총 대피시간, 구간별 통과시간, 평균 체류시간, 최대 혼잡도, 병목 구간·지속시간
- 회차 비교(반복 훈련 시) + 물리적/운영 **개선 권고**

### 4.5 일정 (잠정)

| 기간 | 내용 |
|------|------|
| ~8월 | 사전 준비(캘리브레이션·구역 정의·다채널 셋업·파라미터 협의) |
| **8월 말 ~ 9월 초** | **현장 실증(피난대피훈련)** — 별도 확정 |
| 9월 | 종합평가·결과 보고 |

## 5. 이번 프로그램을 통해 얻고 싶은 것 (자유롭게 작성)

**기술·제품 측면**
- **현장 적용성 검증**: 실제 대피훈련 데이터에서 5대 피난지표가 안정적으로 추출되는지 확인
- **대시보드 실효성**: 관제·의사결정 관점에서 실시간 지표·맵의 유용성 확인
- **종합평가 체계 정립**: 피난 KPI 정의·측정 방법론 확보 및 개선 인사이트 도출
- **확장성 실증**: 다채널(최종 150ch 목표) 동시 처리 가능성·리스크 실측
- **상용화 요건 명확화**: 도면·카메라·도메인 임계값·자원(GPU) 등 향후 요구사항 구체화

**사업·레퍼런스 측면**
- **실증 레퍼런스 확보**: 대기업 현장(CJ제일제당)·삼성금융 협력의 **실제 PoC 수행 실적**을
  피아스페이스 레퍼런스로 확보
- **사업화 발판**: 실증 결과(정량 KPI·현장 검증)를 기반으로 동종 시설(공항·물류·대형
  사업장 등)로 **확산 가능한 기술 신뢰성·사업 모델** 확보
- **협력 관계 구축**: 삼성금융·CJ와의 실증 협업 경험 → 향후 안전·피난 분야 파트너십 기반

## 6. 전제 / 미확정 사항 (확인 필요)

- CJ제일제당 **세부 사업장·대상 구역**, 평면도 제공 가능 여부
- 현장 **CCTV 카메라 수·해상도·구도**, RTSP 접근 방식
- **실증 일자**(8월 말~9월 초 중 확정)
- 도메인 임계값(혼잡 밀도·정렬도·피난 개시 기준), **GPU 자원**(다채널 규모 결정)
