## 4. 리스크 / 수정 필요

레포 사실 기준으로 플래그한다.

1. **로그인 게이트는 mock** — 접속 코드가 아무 값이나 통과하는 프론트 전용 게이트라, `3.2.4`(접근권한: RBAC·JWT·TLS)와 `5.1.4`의 "사용자 관리"는 **미충족**. 실제 접근 통제가 필요하면 서버측 세션/인증으로 교체 필요
2. **세션 리플레이 한계** — 분석 결과(궤적) 재생·재계산까지. 원본 영상 리플레이·회차 비교(KPI 대시보드 `5.2.3`)는 미구현. 검출·추적 오류나 호모그래피 변경 재계산은 원리상 불가
3. **xlsx 서식 검토 요청** — openpyxl 저장이 간트 색상 등 서식을 손상시킬 수 있음. Excel에서 v9 간트/서식 육안 확인 권장
