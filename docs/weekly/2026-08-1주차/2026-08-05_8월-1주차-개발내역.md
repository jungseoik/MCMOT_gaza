## 2. 세션 녹화·2D 리플레이·4대 지표 재계산 (계약 v1.10)

가장 큰 신규 기능이다. 경보 세션 동안의 분석 결과(사람 위치·궤적)를 세션 단위로 저장해두고, 종료 후 도면 위에 그대로 재생하며 **임계값만 바꿔 지표를 다시 산출**하는 기능. 영상이 아니라 분석 결과의 재생·재계산.

- **녹화층**: `system/metrics/recorder.py` — 엔진 `on_tracks` 입력(min_conf 필터 이전 raw 트랙)을 세션별 `data/sites/<site>/sessions/[<floor>/]<session_id>.db`(SQLite)에 기록. 세션 시작 시점의 공간요소·카메라(호모그래피) 스냅샷을 meta로 함께 저장. env `SESSION_RECORD`(기본 on, `0`=끔·롤백)
- **리플레이·재계산**: `system/metrics/replay.py` — 녹화 db를 헤드리스 `MetricsEngine`에 call_seq 순서로 재생. 엔진이 결정적이라 같은 임계값이면 원본과 동일, 다른 임계값이면 그 값으로 재산출(도면·호모그래피 동일 전제 — 역방향 재파라미터화). 기존 집계 `<session_id>.json`은 불변
- **API**: `POST /api/session/{id}/replay?floor=`(result·timeline·frames·site·meta 반환), `GET /api/sessions*`에 `has_record` 노출
- **프론트 ④ 리플레이 탭**: `webui/static/main/view_replay.js` — 세션 이력 선택 → 2D 재생(재생/일시정지·배속 0.5~16×·시크바) + 임계값 조정 → 재계산. 원본 저장값과 재계산값 병행 표시
- **검증**: `tests/system/test_replay.py` — 동일 임계값 재계산=원본 완전 일치(결정성), `d_allow`↓→EPFI↓, `rho_crit`↓→CBS↑. 운영 서버(:8900) 실세션 녹화→재생 확인
- **DB 선정 근거**: 세션 범위 워크로드(append 쓰기→전량 읽기)에 SQLite 적합. 서버 DB(ADR 01)는 서빙/집계 계층으로 역할 분담(세션 .db → ETL 소스). ADR 05 §4.1에 정리

## 3. 간이 로그인 게이트·브랜딩 (PIA×삼성화재)

멀티카메라 시스템(:8900) 진입 화면에 공동 개발을 드러내는 브랜딩 로그인 페이지 추가. **프론트 전용 mock**이며 실제 인증이 아님을 명시.

- **게이트**: `webui/static/main/login_gate.js` — 오버레이 방식. PIA×삼성화재 co-brand 락업(베이스라인 정렬)+타이틀+접속코드 폼. index.html에 `<script>` 한 줄로 포함(제거만으로 원복)
- **mock 동작**: `ACCEPT_ANY`(아무 입력·빈 값 통과) · `REMEMBER=false`(매 접속마다 표시). 실접근 통제 필요 시 서버측 세션으로 교체 필요
- **배경**: `gemini-3-pro-image`로 생성한 아이소메트릭 건물 피난 시뮬레이션 이미지(`webui/static/login-bg.jpg`, 2560×1440). 스플릿 히어로(건물 좌·카드 우), 좁은 화면은 중앙+어둡게 폴백. UI 팔레트(딥네이비/블루)와 일치
- **로고 정리**: 루트 `logo-en/kr.png` → `webui/static/samsung-fire-en/kr.png` 한 곳으로 통합(:8000·:8900 공용 static, git 포함 → 클론만으로 재현)

## 4. 재현성 정비 (순정 우분투 기준)

현장 실증 서버 이관을 대비해, 아무것도 깔려 있지 않은 우분투에서 클론→기동이 끊기던 지점을 Docker로 재현·해소.

- 신규 Miniconda **ToS 미승인**으로 `conda create` 차단 → 부트스트랩에 `conda tos accept` 단계 추가(`c91832f`)
- CAD `cv2` 런타임 **libGL 누락**(`libgl1`·`libglib2.0-0`) 자동 설치(`9130eff`)
- DWG 변환 **libredwg 빌드 의존성**(python3·libpcre2-dev) + 편집기 ODA 부재 시 libredwg 폴백(`9c70700`)
- 웹서버(FastAPI·uvicorn·multipart) 의존성을 webui-only에서 **core `requirements.txt`로 승격**, :8910 편집기 기동 절차·문서 정합(`99ca7e2`)

## 8. 다음 단계 / 한계

이번 주 산출물의 남은 과제는 다음과 같다.

1. **세션 리플레이** — 현재는 분석 결과(궤적) 재생. 원본 영상 리플레이·회차 비교(KPI 대시보드)는 미구현. 검출·추적 오류나 호모그래피 변경 재계산은 원리상 불가

3. **이관 검증** — 재현 절차는 Docker(CPU)까지 확인. GPU 실장(torch cu130·TRT 엔진 재빌드)은 실증 서버(Blackwell 아님)에서 재측정 필요
